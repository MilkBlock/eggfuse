# FEPT：显式父实例与静态 Cell 模板

普通输出写作 `T(A, B, …)`。T 是模型在实例化之前选择的静态 Cell 模板，A、B 指定本次独立父事实的物理身份和版本。表范围、签名桶、发给接收端的候选窗口都不足以指定 A 或 B。

**分子**为本次归属推导中新建、并且在终图以原始来源可见的不同构造节点数。保留另一列记录所有首次构造，以便分析后来合并、隐藏的中间事实。输入图、普通函数写入、重复 intern 请求和仅仅提前预留的实体不增加分子。

**分母**计所有实际签发的模板实例提案，包括失败的提案和独立签发的子 token。按同一个 Run、源顺序和可观察语义与对照比较。组合收益要落实为真正不再签发的内部提案；被验证后再归给祖先的独立模型决定仍须付费。若一条路径把独立选父交给接收端，则把该配置标为不符合协议，不能只从分母删掉这种动作来计算一个更高的 FEPT。

## 验证器可以消费哪些证据

- 对外部父，直接按模型给出的引用读取真实行，检查表、版本、端口、共享变量与原 Run 的可见性。只有规则确实要求相等时才按当前等价类比较；保留原来源。
- 对内部边，模板给出先前哪条操作的哪个**实际返回端口**。构造命中已有节点时应传递已有节点的引用；不能一律推断为本 Cell 的新成员。
- 编译器能证明操作数和结果唯一的整数运算、投影及函数请求可以精确执行。记录其实际点查代价。如果需要从多个关系成员中选择某一个父，模型必须在当前或另一份付费 token 里点名。
- 跨 Run 只在原释放边界激活，同时重查会变动的版本、可见性和条件。提前知道静态接线不会使未来的写入提前可见。
- 检验是否真的由模板决定后继，可在普通执行中禁用该后继的外部模型提案，并记录验证器的独立父候选遍历次数。源程序的独立对照及详细审计可以重新匹配；这部分不能用作被测路径的输入。

例如，`T12(A,B)` 可以规定先执行 `u=T1(A,B)`，再用 `u` 的实际返回引用与 `A` 执行 `T2(u,A)`。若第二步的输入是未指定的任一 `C`，模板仍缺少该选择。把整页 `C` 交给验证器扫描，不能证明这份 token 指定了两步推导。

## 更正历史成绩

3mm 显式父提案过滤基线仍为 **92,658 / 558,074 = 0.16603**。其中包括 334,594 份单父、220,972 份具名多父提案和 2,508 份独立子包。唯一确定的剩余规则条件仍由 Rust 检查。节点与提交账本可见 [构造审计](../benchmarks/pass3-cell-gpu/token-constructor-births/README.md)。

此前 0.398、0.819、0.973 等数据使用了类别、区间或多父签名集合动作；接收端需要恢复具体成员。**从显式父 FEPT 成绩线撤下这些数值。** 原始实验保存为“外部描述符传输产出”，用于比较传输字节、重建成本和 RSS。历史 JSON 中的 `fept`、`per_packet.forward` 等字段名沿用当时的归档格式。报告和图册引用这些历史数值时均采用现行分类。

从一个被接受的 Spine 根可追溯到很多后继，只说明血缘关系。仅在一份事先选定的静态组合 token 用所列父引用和已证明的内部接线独立完成了后继，并在原 Run 确实免去了对应的外部提案时，才能计入组合 FEPT。尚未部署的图匹配、回放或事后机会界，均应单独报告。

## 首轮合规结果

同一过滤版原生引擎上，sum-bits 的叶模板为 2,691 / 12,662 = 0.212526，一跳静态组合为 2,691 / 12,423 = 0.216614。3mm 的叶模板为 92,658 / 558,074 = 0.166032，一跳组合为 92,658 / 554,626 = 0.167064。这两组的第二跳均未进一步免发。供体中实际观察到的接线直接迁移时，两组都没有提高；保留供体选中的消费者、由编译器在加载时补齐相同类型的明确构造操作后，实际接管分别为 141、3,448 次。[同一显式父协议的配对消融](../benchmarks/pass3-cell-gpu/filtered-explicit-parent/README.md)

在另一个独立双父消融中，生产者外部包在 RHS 前指定两条构造指令。它们实际返回的 PotentialExtractedExpr 与 TCPair 两个具名父，在下一 Run 直接交给辅助完成规则。3mm 实际少发 928 个独立子包，显式父 FEPT 从 0.166032 增至 0.166308。该辅助规则本身没有新增最终可见构造节点。此结果未与上述单原子消费者组合一起测试，不能叠加。前者证明可以少一次决定，后者还需要按每个成功实例核对究竟生成了多少不同的终图节点。[严格双父接线](../benchmarks/pass3-cell-gpu/strict-dual-return/README.md)
