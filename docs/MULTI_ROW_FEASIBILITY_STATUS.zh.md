## 本轮确认

前一轮完成了工作区迁移，属于实际进展：源码逐文件 SHA-256 一致，独立 Git 仓库与环境在硬盘上，3 个已有 GPU 冒烟测试通过。它只证明迁移可用，不证明本架构。

本轮在读取已有实现时发现，旧工作包含固定实例矩阵、物理载荷共享和有界 union 闭包，不能作为共享模板、同图多序列的完整证据。

用户澄清二维布局：每个 row 有多个 instance token；行编号和行内 token 位置分别做旋转编码，内部端口可以再加一层。这取代了原规划中“一个 row 等于一个提案槽”的错误定义。尚未实现这个新接口，旧 `[B,279]` 实验不能复用为它的验证。

## 紧接着需要验证的接口

先定义模板端口怎样解析到 `(row, position, port)`，以及编译器给出的源到目标投影怎样重写该地址。行旋转和行内旋转必须独立，不能把两者混成一个标量位置。读取要拒绝过期 generation、未公开成员和没有合法投影的旧地址。

这些引用测试只能证明寻址机制；随后仍需把它放进共享模板实例和真实同图 union/接管路径，不能把正确读取几组旋转 key 当作整个架构已经可行。
