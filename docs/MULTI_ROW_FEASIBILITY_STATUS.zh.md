# 多 row 架构可行性证据账本

目标：证明《E graph 多 token row 神经推理研究与实施规划》描述的架构可行。目标仍在进行，不能用下面某一项局部检查宣布完成。

最新验收重点：神经网络在同一张图中快速生成多 row、行内多 token 的互补输出。压缩不再是成功条件。

工作区：`/Volumes/EggFuseWorkspace/worktrees/eggfuse`。构建和实验通过 `/Volumes/EggFuseWorkspace/bin/run-eggfuse` 使用硬盘环境。

## 本轮确认

前一轮完成了工作区迁移，属于实际进展：源码逐文件 SHA-256 一致，独立 Git 仓库与环境在硬盘上，3 个已有 GPU 冒烟测试通过。它只证明迁移可用，不证明本架构。

本轮在读取已有实现时发现，旧工作包含固定实例矩阵、物理载荷共享和有界 union 闭包，不能作为共享模板、同图多序列的完整证据。

用户澄清二维布局：每个 row 有多个 instance token；行编号和行内 token 位置分别做旋转编码，内部端口可以再加一层。这取代了原规划中“一个 row 等于一个提案槽”的错误定义。已有确定性接口原型验证二维地址和共享模板视图，见 `benchmarks/multi-row-cell/README.md`。这不是神经引用生成的证据，旧 `[B,279]` 实验也不能复用为二维序列神经生成的验证。

## 初始实验要求（下方记录进展）

建立一次神经前向在多个 row 生成关联 token 的任务，至少包括共享输入、跨 row 产生者／消费者引用和需要联合覆盖的义务。模型不能只对多个独立样本作 batch inference，也不能由 CPU 预先把正确答案分给各 row。

比较联合多 row、独立多 row、带缓存的逐 token 自回归、单 row 分块生成。固定目标工作量和正确性口径，报告合法完整批比例、重复／缺失／冲突、引用错误、实际前向调用数、延迟与有效吞吐。移除行间交互、遮蔽前一步生成的 latent、打乱行布局和扩大 n 都应有对照。

先验证这件事，再继续扩大 union／ownership 任务与真实 eggcc 接入。压缩指标仅作为资源观察，不作为这轮结论。

## 神经生成里程碑 2026-11-18

`benchmarks/multi-row-generation/README.md` 记录真正的同图神经生成。每个 row 有多个 token。第一轮需要从整张图找到未提供的匹配绑定；第二轮直接读取生成的 Pair latent，再生成跨行 Chain 引用。没有 CPU 答案回填。

首轮只训练 1/2 环，四个模型都学到了与训练标签一致的错误“反向”规则，长环验收全部失败。这批结果已在 576063f5 保留。加入能区分方向的 3 环训练后，保持网络、预算和种子不变，在新冻结的非双射合流图上，两个行内查询模型和一个联合模型通过 512/512；另一个联合模型为 507/512，不能宣称统一成功。

每个新图中确有跨行生成依赖；清空第一轮生成的 latent 后，第二轮完整结果全部失败。计时包含初始输入准备、神经生成、地址解码和绑定到实际 latent 的 GPU 验证；所有 timed graph 与独立 CPU 逐图判定一致。计时的串行对照不是自回归网络，因此强 AR 对照继续保留为未完成条件。

当前工作没有证明自由分配输出 rows、可变匹配数量、union、ownership 协调、真实 eggcc 或强规范 latent。下一步应优先检查更长闭环生成及变量数量的互补输出，建立真正的缓存自回归基线；不能继续只增加同类两步例子的数量。

## 长接续与因果基线补充，2026-11-18

这次检查发现，两轮生成通过不能外推成长接续成功。四个冻结连续模型到第六轮全部失去累计正确性；继续用真实生成状态训练到四轮后，训练回放和留出尾链也在第十一轮全部失败。负面结果保留于 `benchmarks/multi-row-generation/depth/`。

随后做配对实验：相同数据、预算、参数维数，比较原始连续状态与“模型自己预测的规范符号接口”。后者仅把自己的四个类别预测变成 40 维 one-hot 加 24 维零填充；没有教师状态、CPU 补查回填或错误纠正。两种留出拓扑各 256 个随机编号/布局/数值样本，两个种子均通过 12 轮全部指针、字段、地址及实际 token 格式检查。连续对照在第十二轮只剩 0–10/256 正确。独立 CPU 进程读取保存输出并核对模型哈希后再次通过四份验收。

这里的 512 个样本只有两种无标号拓扑，有限路径端点也会进入周期。结论只覆盖重复消费生成接口，不覆盖任意深度新推导、完整 latent 信息保真或饱和。详见 `benchmarks/multi-row-generation/typed/README.md`。

真正的逐 token 因果基线现在已训练：可见全部已知源输入，缓存实际生成前缀的 K/V，没有未来输出和教师前缀。早期错误限制已知输入的版本单独归档，未用于最终结论。两轮同图的含输入准备、GPU 验证计时，规范接口批量生成比当前因果实现快 5.93–8.10×；所有计时图均正确。双方训练分布、初始化和预算不同，因此不能称为纯架构消融，也不能直接推出真实 eggcc 收益。详见 `benchmarks/multi-row-generation/causal/README.md`。

下一门槛是**互补分工而不只是批处理**：取消固定的一锚点一输出，加入零个/多个合法输出、重叠候选与跨行未完成义务，测完整合法批数/秒、重复/遗漏、引用错误、冲突与修正轮数。现有结果证明了有限任务上的引用生成和接续，尚未证明模型自行决定 rows 如何合作。目标仍保持进行中。

## 无锚点集合生成，2026-11-18

`benchmarks/multi-row-generation/allocation/README.md` 实现了上述方向的第一项实测：8 个输出槽不绑定源锚点，每槽可自行选择任意两个输入指针或输出空槽；每个源实例可以有零个或多个匹配。训练使用无序集合匹配监督，推理没有候选预枚举、去重或 CPU 回填。

四个模型均未通过。在 4×2 布局的 256 个 IID 图上，联合两种子为 63/55 个完整图，行内交互对照为 84/115；多重度结构留出则只有 28/9 和 35/31。去除空图后，IID 非空完整率进一步下降。独立 CPU 审计确认结果。联合模型依赖行间消息，但重新训练的行内对照更好，不能将更多通信直接当成更好协作。

最佳 IID 配置仍有 126 个图仅因遗漏或重复失败，匹配本身和字段值均合法。这个结果将下一步指向完整覆盖及认领竞争的训练/状态契约。神经路径约 1.54–1.60 ms，精确 GPU 对照约 0.40–0.42 ms 且完整正确；本任务没有神经速度收益。旧固定分工任务的速度比不适用于此任务。

这仍是单阶段独立原型，没有可变集合跨阶段接续、union 或 ownership。目标保持进行中；不能用试验设施检查通过替代模型验收通过。

## 覆盖监督配对，2026-11-18

`benchmarks/multi-row-generation/coverage/README.md` 保持推理网络不变，只增加训练时的软绑定覆盖与总输出数量约束。四个旧模型权重不变，16 份旧面板逐项复现；新模型使用相同初始化种子、数据与训练预算。

IID 4×2 完整图为 63→78、55→156、84→138、115→101；收益不稳定。新的双侧三重度非空图为 36、54、44、60 /192，但新的 A 四重度非空图只有 25、3、0、0 /170。另一布局同样未通过，训练回放也远未全对。8 次独立 CPU 审计核对原始神经 logits 与生成 token，确认所有模型仍严格失败。

该消融把“软覆盖总量接近”与“离散义务恰好覆盖一次”区分开：一个模型遗漏减少而重复增加，说明总量监督不足以自动得到互补分工。网络前向成本没有改变，也没有产生可替代精确 GPU 对照的速度收益。

下一项应检验同图多 row 分轮生成，让后续行内位置直接消费此前各 row 实际生成的认领信息，比较反馈能否降低重复和遗漏。保持原总体目标及所有未完成门槛；当前证据不构成完整架构可行性证明。

## 实际历史反馈，2026-11-18

`benchmarks/multi-row-generation/streaming/README.md` 实现每轮每行输出一个 token。90 维 token 包含实际生成的 64 维 latent 和自身预测的硬符号，后续轮直接消费；没有教师历史、CPU 补齐或确定性去重。配对的 blind 模型采用同参数形状、同初始权重和训练预算，但屏蔽历史载荷。

四个模型均失败。4×2 的 IID 完整图，feedback 两种子为 34、43 /256，blind 为 94、80；剔除空图后为 4、11 /224 对 63、50。历史擦除和同行历史干预确认后续 token 依赖实际生成历史，但不能证明该依赖有收益。四次独立 CPU 审计及初始权重/因果边界检查完成。

保留完整 token 的生成延迟为两轮 3.28–4.27 ms、四轮 6.96–7.41 ms。多 row 降低顺序轮数，却没有建立同正确率下的速度优势。这是单阶段输出，不能升级为跨 Run 补全证明。

当前神经原型还在重学模板可确定的字段。已核对实际引擎 `Template/Op` 与 `known_results::Plans` 的槽位投影/来源契约，后续应将共享静态语义接入神经接口。不过冻结现有绑定时，字段投影仅能挽回两个 feedback 模型的 4、10 个 IID 图，不能代替主要的认领与覆盖问题。总体目标继续保持未完成。
