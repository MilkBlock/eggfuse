# RipSat-Math-20-v1 数据集指标

**一个样本 = 一个初始局部 E-graph，在固定 Ruleset 和固定边界下，经原生执行核验达到不动点的一次 completion。** 初图含 1–20 个可见 e-node，终图可以超过 20 个。合法中间状态及其下一枚完整 Cell Token 是派生训练样本，单列数量。超时和预算截断单列，不进入饱和样本分母。

每次发布在报告首页使用以下两行，尖括号填入实测值。

```text
RipSat-Math-20-v1 · 24 Rules · 初始节点 ≤ 20 · <N> 个饱和样本
Uin <初图数> · Uout <终图数> · ER <平均倍数>× · DEPTH <平均步数> 步 ｜ DR <百分比>
```

| 指标 | 计算口径 | 回答的问题 |
|---|---|---|
| Uin | 不同初始 E-graph 的结构等价类数 | 有多少种起点？ |
| Uout | 不同原生饱和终图的结构等价类数。多个初图收敛至同一结构只计一次 | 有多少种计算结果？ |
| ER | 对每个初图先算终图可见 e-node 数 / 初图可见 e-node 数，再求均值 | 一个入口平均扩张多少倍？ |
| DEPTH | 从初始证据到新增有效计算的最长实际因果链，按链上的计算步数计，再对入口求均值 | 完成一次推导平均需要多深的连续计算？ |

**DR（Diversity Retention）= Uout / Uin。** 例如 6 种初图收敛到 2 种终图，DR 为 33.3%。低 DR 可以揭示终态集中，也可以反映有价值的多入口收敛。解释 DR 时同时给出 Uin、Uout 的绝对数。空集的 DR 和均值记作 N/A。

## 结构与节点怎么数

- 初图和终图采用相同的、带类型的 E-graph 同构判定。忽略物理地址、节点排列、e-class 编号，允许边界变量在相同类型和接口角色内一致地双射重命名。保留算子、语义字面量、字段角色与顺序、子引用、共享结构、e-class 成员关系，以及声明的根或接口。边界槽号按变量处理，计算中的数值常量按原值处理。
- 例如 `Mul(a,a)` 与 `Mul(b,b)` 等价；`Mul(a,a)` 与 `Mul(a,b)` 含有不同的共享关系。验收须比较完整 E-graph，哈希可用于分桶，单棵提取表达式、相同节点数或相同提取成本均不足以确认同构。
- 按原生可见 e-node 计数，包含 `RipenInput` 和显式常量节点。节点字段里的槽号、地址、字面量及 e-class 容器不另计。多个消费者引用同一节点只计一次；同一 e-class 中的不同 e-node 各计一次。

## 深度与汇总怎么复核

- 使用固定版本的原生参考见证。初始证据深度为 0；一步有效计算的深度为 1 加上其实际前驱的最大深度，无计算前驱时为 1。依赖须来自真实输入、等价成立或消费所需的发布证据；必要的中间计算保留。两个独立计算恰巧串行执行不形成依赖边。已经饱和的入口深度为 0。该指标衡量给定见证的因果深度，最短证明深度是另一个研究问题。
- 首页 ER、DEPTH 按**不同初图等权**，以免重复抽取某个入口改变数据画像。同一初图有多条合法轨迹时，按数据版本预先固定一条参考见证用于 DEPTH，其余仍可用于训练。缺少可核验依赖的 DEPTH 标为 Unknown，均值旁列出有证据的入口数 / Uin；全部缺失时填 N/A。
- 全集及各划分分别去重，全集的 Uin、Uout 独立计算。随卡记录 Ruleset 指纹、节点计数与规范化版本、原生执行及见证版本。若同一规范初图在固定语义下产生多个不同规范终图，单列冲突并核查边界、语义或重放差异，再发布该版本的 DR。
