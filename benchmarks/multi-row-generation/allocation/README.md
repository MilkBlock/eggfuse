# 无锚点的同图多 row 集合生成

这是 MLX/Metal 独立神经原型，尚未接入 egglog/eggcc。重点是互补生成，不是压缩。它取消了上一版“一源锚点固定产生一个 token”的任务分配。

## 实际执行什么

同一图有 4 个 A 实例端口、4 个 B 实例端口，每个带 key 和 value。A/B 是有身份的输入实例，字段相同不自动合并身份。每个 `A.key = B.key` 的有序实例绑定是一个义务。因此同一个 A 可以没有匹配、匹配一次或匹配多次。

模型面对全部原始输入，一次输出 8 个潜在 token，分为 4×2 或 2×4 的二维布局。每个输出槽自己预测：是否激活、A 指针、B 指针、key、左右 value。查询只由输出坐标初始化，没有给定源锚点，也没有给定合法候选列表；不能把这当成已知匹配上的调度。

训练标签是无序集合。Hungarian 分配只在 CPU 训练期间对齐预测槽和真值，梯度更新没有固定的正确输出顺序。推理中没有 Hungarian、排序、去重、符号过滤或 CPU 补齐。GPU 检查只读预测，CPU 在全部前向完成后审计。

网络使用三层查询交互、源输入 attention 和共享指针／字段头。联合模型允许所有 row 的查询交互；独立模型将查询交互限制在行内，但两者都能读取整张图的原始输入。两类都使用稠密计算加 mask，独立版本不是稀疏性能实现。

## 固定验收口径

[PROTOCOL.md](PROTOCOL.md)在训练前固定了预算、种子和数据。训练有 4096 个图、44 种实例多重度结构，每种 key 在单侧最多出现两次。留出多重度集的某个 key 在 A 侧出现三次，有 13 种不与训练重叠的结构。IID 和留出各 256 个新样本，两个布局检查的是相同样本，不算额外独立图。

最终检查要求输出的合法绑定集合完整、无重复，每个字段与引用地址正确。空集合也在 IID 中；报告必须同时看非空样本，不能让“全输出空”取得的通过数掩盖问题。`missing`包含绑定缺失及字段错误造成的无效义务；`diagnosis.json`另外分离真正的绑定遗漏和字段错误。

本实验只生成一阶段的可变集合。没有验证生成后的 token 再次进行跨阶段推导，也没有 union、ownership、未知 key 编码、扩大图规模或自主停止。此前 12 轮规范符号实验不能自动补上这些缺失。

## 实测：未通过互补生成

所有模型使用最终第 4000 步权重，没有挑选种子或中间 checkpoint。4×2 布局结果如下，2×4 的完整记录保留在 `results/`，结论相同。

| 模型／种子 | IID 完整图 /256 | IID 非空完整图 /224 | 留出多重度完整图 /256 |
| --- | ---: | ---: | ---: |
| 联合 / 1703 | 63 | 34 | 28 |
| 联合 / 1709 | 55 | 24 | 9 |
| 行内交互 / 1703 | 84 | 54 | 35 |
| 行内交互 / 1709 | 115 | 84 | 31 |

四份独立 CPU 审计从保存的预测重新计算，均确认严格验收失败。它们的退出码 1 是实验结果，不能写成通过。4 项接口/分配/审计检查通过只说明试验设施按契约工作。

联合模型在推理时切断跨 row 查询通信后，IID 完整图从 63→15、55→38，说明其行为确实依赖行间信息。但**重新训练的行内交互对照反而更好**，不能据此声称增加行间 attention 提高了整体性能。行内版本仍读完整源图，不能称为完全独立的局部计算。

错误主要不只是“不会匹配”。以行内模型 1709 的 IID 为例：

- 115 个完整图通过。
- 126 个失败图只有绑定遗漏或重复，没有非法绑定及字段错误。
- 4 个图只有字段错误。
- 全部 256 图累计遗漏 105 个绑定、重复 95 个合法绑定，只有 2 个非法绑定。

这些类别不是全部互斥的错误分类；完整分解见 `results/diagnosis.json`。例如某图需要 `(A1,B1)` 和 `(A3,B1)`，网络输出 `(A3,B1), (A1,B1), (A3,B1)`；三个 token 单独看都合法，合起来重复执行。另一个图需要四个绑定，网络正确给出三个却漏了第四个。这正是本轮要暴露的协作问题，不能靠事后去重或补齐把它隐藏掉。

## 速度及确定性对照

同一批输入、batch=1，每种布局/分布计时 32 个图，模型执行顺序轮换。计时包含特征构建、上传、神经生成、地址解码及只读 GPU 检查，CPU 事后审计和编译预热不计入。

神经模型中位数 **1.539–1.602 ms/图**；纯 GPU 精确等值连接加固定容量打包为 **0.399–0.415 ms/图**。精确版本在完整两个 256 样本集、两个布局均通过，不只是计时样本通过。它只作为对照，没有被拿来回填网络。

这轮神经网络既没有相同正确性，也没有延迟优势。不能继续使用上一轮固定输出位置任务相对因果生成的 5.93–8.10× 来支持此任务。这里仅有 8 个输入实例，也不能外推大图吞吐。原始延迟样本、有效完整图/秒及模型哈希见 `results/benchmark.json`。

## 接下来的具体问题

本轮只验证了通用 self-attention 加无序集合监督这一种方案，失败不构成所有多 row 网络的不可能性证明。下一步应隔离“覆盖约束是否缺失”：先保持网络不变，在训练端增加总义务数与各绑定覆盖量的约束，与当前仅逐 token 匹配损失配对。推理仍不能读取正确匹配表或做确定性去重。若训练目标不足以改善，再让下一轮显式消费前一轮生成的端口认领信息，检验模型是否能修正重复和遗漏。

旧验收集从此仅作诊断；下一轮仍须预先冻结新的结构族，保留全部种子。最终还必须把可变集合生成接回真正的生成状态消费，并完成 union、ownership 和强表示契约，才能宣称整体架构可行。
