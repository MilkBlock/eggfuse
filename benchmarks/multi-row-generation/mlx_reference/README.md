Frozen MLX reference implementation from commit 9320cce7 (EggFuse 0.1). Only the comparison runner imports this directory. To reproduce a historical MLX script which imports eggfuse, prepend this directory to PYTHONPATH in its MLX environment. The installed EggFuse 0.2 package supplies offline tools.
