# Cross-Run projection experiment

Freeze six final models before looking at evaluation outputs. Run `make` first, then `finish`. `finish` can read only the generated Pair token sequence, two-dimensional locations and four fresh Request records. Both stages generate into eight unassigned output slots on one graph (4 rows × 2 positions). `make` retains the previous feedback decoder's two causal emission rounds. `finish` emits the eight Result proposals jointly. Results carry their chosen Pair slot and Request slot. Exact verification checks the original source identities, presence of their actual generated Pair and complete source obligation set.

All arms start make from the same corresponding streaming feedback checkpoint (seeds 1703 and 1709). The two-rule baseline uses the learned field head at both stages. The other arms gather fields from the selected source rows using the two actual Rust recipes. Only the auxiliary arm also trains field readouts from the latent. Hard pointer choices select the gathered values. There is no supervised pair lookup at inference. Training uses the same activation and pointer losses for all arms. Offline Hungarian supervision aligns free slots for losses only. Fixed Adam lr 0.0003, batch 32, 2000 updates on the same 4096 graphs, final checkpoint only. The earlier streaming checkpoint saw allocation-task graphs; structural holdout here applies to the new two-rule training corpus, not a claim of unseen scalar values or unseen unordered joins in pretraining.

At test, mask the two explicit parent references only in the input of finish. Keep latent, row coordinates and token payload available. Also mask latent and references together as a diagnostic. Masks leave the original emitted Pair and its auditor lineage intact. Measure graph-level hard results, including all failures. Evaluate the fraction of nonempty graphs whose complete Result set is legal and exact, missing obligations and repeated bindings.
