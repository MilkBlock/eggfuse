# 两条规则跨 Run 的静态投影消融

在两组父引用碰撞留出集上，静态投影加训练期字段头的第二个 Run 取得 65 和 67 张完整非空图，分母均为 512。仅投影为 39 和 37，原版字段预测为 49 和 41。保留辅助头的两个种子都改善了整图结果。仍有超过一半的合法绑定缺失，无法用当前模型替代精确执行。

## 阅读和运行 Python

[训练脚本](examples/train.py) 包含 MLX 的前向、损失、梯度和 Adam 更新。[推理脚本](examples/infer.py) 从 `eggfuse` 包加载模型并直接消费原始 A、B、Request 输入。[调用说明](examples/README.md) 给出可复制的命令和碰撞示例。[包内模型](../../../python/src/eggfuse/model.py) 实现两个 Run 的设备数据流。

```python
import eggfuse
import mlx.core as mx

model = eggfuse.load_model(checkpoint_directory, plan_path)
(make, finish), pair_token = eggfuse.infer(model, a, b, requests)
mx.eval(make, finish, pair_token)
```

`pair_token` 的形状为 `[batch,8,90]`。前 64 维是实例 latent，随后依次编码激活位、两个父引用与三个字段。第二个 Run 接收这个张量、坐标与新 Request。源码中的静态计划在离线阶段通过真实 Rust 编译器导出。GPU 根据网络选出的父引用读取相应字段，同时保留原始预测的实例引用。错误选择的父仍会使义务失败。CPU 参与离线训练和事后审计，定时路径包含原始整数输入的准备、MLX 设备执行、两个输出和 Pair tensor 的物化与同步。

## 输入、规则和判据

`make` 连接同键的 A、B 并发布 `Pair(i,j,k,x,y)`。`finish` 根据 **两个** 源实例地址将 Pair 与 `Request(i,j,t)` 连接并发布 `Result(i,j,t,x,y)`。Rust Cell CPU 独立执行了 768 个评估输入的两个 Run，全部 1,536 个边界上的绑定、发布关系都与冻结标签吻合。[规则源码](compiler/rules.egg) · [Rust 逐面板核验](compiler/panel-audit.json)

4,096 张本次训练图全部排除 `(k,x,y)` 相同且父地址不同的 Pair。生产者共同从历史 streaming 检查点热启动，早期单规则预训练允许字段值重复。专门留出的是需要 `finish` 区分这些父的两规则任务。每个碰撞面板是 128 对请求反事实，两个面板合计 512 张非空图、256 对请求、910 个 Result 义务。同一对中 A/B、tag、Request 位置和干扰项相同，仅一个请求的父实例发生变化。两组都复用原键词表和 4×2 布局。[数据清单](data/split-manifest.json)

完整图要求覆盖每一项 Result 义务，且引用合法、字段正确、产生该结果的 Pair 的字段也正确，重复或多报均判失败。遗漏与重复按合法实例绑定计数。字段错误和非法引用另行记录。因此有效绑定即使字段错误，也不能将其计作缺失绑定。[审计代码](data/crossrun_audit.py)

## 第二个 Run 的结果

下表合并左右父碰撞面板。每行延迟是冻结的两个面板各 32 张图通过已安装 Python 包的单图预热后中位数，共 64 次同步调用。训练、模型加载和事后 CPU 审计单独执行。

| 模型 | 种子 | 完整非空图 /512 | 重复绑定 | 遗漏绑定 /910 | 非法输出 | 屏蔽父引用后完整图 /512 | 两个 Run 中位数 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 原版字段预测 | 1703 | 49 | 3 | 547 | 380 | 0 | 5.17 ms |
| 静态投影 | 1703 | 39 | 10 | 636 | 439 | 2 | 5.74 ms |
| 静态投影＋训练期字段头 | 1703 | 65 | 13 | 550 | 367 | 4 | 5.32 ms |
| 原版字段预测 | 1709 | 41 | 18 | 582 | 444 | 3 | 5.36 ms |
| 静态投影 | 1709 | 37 | 7 | 586 | 485 | 1 | 5.43 ms |
| 静态投影＋训练期字段头 | 1709 | 67 | 16 | 579 | 429 | 1 | 5.54 ms |

原版、纯投影、投影加辅助头在普通 IID 的完整非空图，种子 1703 为 13、9、23 /162，种子 1709 为 8、9、8 /162。两个碰撞面板均改善的趋势没有在普通面板的两个种子上重现。

以投影加辅助头为例，种子 1703 的生产者为 255 张碰撞图供应了全部所需合法、字段正确的 Pair，消费者最终完成其中 65 张。种子 1709 分别为 277 和 67。其余的 190 和 210 张就绪图已经有正确父，仍存在消费、覆盖或额外输出错误。训练期字段头改善了这个有限任务的一部分，尚无法解决跨 row 分工。

仅屏蔽 `finish` 输入中的两个显式引用时，六个模型的生产者 Pair 均保持逐位相同，连续 latent 和位置信息仍然可见。投影加辅助头对反事实请求的两次变体均准确选中变更父并正确生成该项的次数分别为 27、14 /256 对，屏蔽后为 1、0 /256 对。这一指标只检查变化的那项，整图完整性另计。当前权重高度依赖显式父引用。当输入通道被屏蔽，模型面对训练时未见的损坏输入，因此该对照只支持通道依赖判断。

## 复核与适用范围

- 六份最终权重按预先冻结的两种子、同数据、同预算取用。[实验协议](PROTOCOL.md)
- 54 个模型／面板／屏蔽组合全部通过了事后 NumPy 指针、字段、祖先和覆盖度量的重算。安装版重跑所得 13,824 次有重复计数的图级输出，其两个 Run 的离散输出和完整 90 维 Pair 字节均与实验记录相同。独立碰撞样本的计数仍按上述 512 张图解释。[完整指标](results/metrics.tsv) · [安装版延迟样本](results/api-timings.json)
- 仓库外安装 wheel 后可以训练或加载固定权重。用公开样例重训了 aux/1703 的全部 2,000 步。重复执行原训练脚本也会得到不同最终权重，因而六模型比较引用存档权重。固定相同权重的推理通过了逐字节核验。[重训和单步梯度对照](examples/example-validation.json)
- 神经时间测量来自独立 Metal 原型，覆盖这两个 Run。对 eggcc 新增的 8 个 Bril 源程序已另行用原生编译器跑完前三个优化 pass，受控规则消融和这些程序的后续训练使用独立的数据来源。[eggcc 工作负载](../../eggcc-diversity/README.md)
