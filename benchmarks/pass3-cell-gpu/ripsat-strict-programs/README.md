# Compile native RipSat donor evidence into a strict Cell program

The normal artifact is an executable selector for the [explicit-parent Cell CPU engine](../explicit-parent-cell-composition/README.md). The compiler joins three separately checked facts: an authentic physical donor producer/reader pair, a typed return and exact consuming read in the native isolated RipSat history, and an independently re-derived source/target Cell program. The portfolio contains 79 sampled cards from dot-product and jacobi-1d; sampling includes targeted as well as automatically proposed regions. It is not an exhaustive search over eggcc or all possible RipSat cells. [Native source artifacts and trust index](../ripsat-donor-evidence/README.md)

## What is executable

Both donor programs produce the same default edge on both targets: **rule 143, constructor operation 1 → rule 55, LHS pivot 0**. Its constructor table is Single. Re-evaluating the producer operation in the dot-product terminal graph gives argument class 4 and result class 5. The corresponding local rule application is event 0. It writes fact-version token 6 at the exact head site. Event 8 consumes token 6 at the Single body site using occurrence index 0, parent-port 8. These event and value numbers are local to this particular graph.

The original dot-product execution separately records producer serial 1,737 in source epoch 131, consumer serial 1,822 in epoch 135, and the same physical FactRef (packed ID 3,835,405,795,329) with version 131 on the consumer. For a *new* instance, the projection comes from the original rule schema: the constructor’s ordered arguments/result bind the consumer slots. The existing Rust engine still requires that particular selected producer instruction to return a fresh physical FactRef and later checks its validity, version, watermark and original schedule. A compiled candidate by itself creates no fact and establishes no endpoint speedup.

The two linked donor cards yield one unique target **strict_named** plan, with SHA-256 **34e6bc837c3c60b3384c0d43e2d05ab814c5421722140c834dc4304980c5c465** (canonical JSON of the execution spec). Two other full cards verify a new NoAlias transpose and its static unary consumer. Their local history contains no subsequent consuming write→read edge for the transpose. They are exposed separately under `strict_named_static_consumer` as `[446,0,446]`. The remaining 75 nominated cards supply no default authorization.

The augmented dot-product capture originally nominated op 5 and rule 151. Its authenticated native history really contains a different edge, **24/op4 → 65/pivot0**. Event 8 writes Bop([0,11,11])→14 at the nested RHS constructor; event 18 reads that same fact token 14 from the producer’s original output port 13. The two initial Bop rows both have the named PtrAdd coordinate corresponding to final class 9, distinct from the new Add class 0. The full rule body confirms op 4 is the unique matching constructor instruction; op 5 is a set. The original Pass 3 trace corroborates op 4 using model serials 9,080→9,736 in epochs 788→797, but the isolated native sample was grounded from producer serial 12,496. The raw byte receipts support *two separate instances*. This route is reported in `mapped_decisions` / `independently_corroborated`, with its own evidence under the supplemental selector. The default matrix does not present it as a same-instance physical observation. [Sum-bits artifact](sum-bits.json) · [3mm artifact](3mm.json)

## Proof boundary

- The application independently supplies the donor program files and uses a producer trust index outside the mutable sample bundle. Digests bind the original donors, their physical origin captures, the native executable and each authentic native acceptance receipt. The receipt pins the raw entry, initial/final e-graphs, report and history. The compiler additionally checks the original .egg source bytes and rule bodies, scope, complete saturation, export status and checks, and rebinds the scoped named seed ports to actual grounded terms. Observation-only, stopped and partial-scope candidates cannot authorize a normal edge. Compromise of the trusted producer/index remains outside this offline integrity model.
- The compiler evaluates the actual donor operation on typed native graph rows, verifies a new distinguishing output incidence and checks source byte spans, produced value columns, required fact-version tokens, read-result classes, Write→Read identity and parent-port correspondence. A terminal e-class, two counts, a history rule name, a repeated equality in one donor, and positive frequency cannot supply any of these missing facts. An underived or ambiguous operand is refused.
- The runtime grammar permits a seminaive sole constructor consumer with distinct typed query slots and complete RHS projections. The producer must perform an actual `let` constructor at the specified physical operation. Extra independent LHS parents, unsupported guards, and a Set treated as a new constructor return are rejected. Re-linking requires unique matching target schemas including effects, sorts, interface, referenced table declarations and source ruleset; the target is checked again. The target runtime retains its own original effects, merge behavior and rollback/refusal conditions.
- Two-edge assembly additionally requires the same donor and matching immediate producer/consumer serial, ordinal, rule, Run, exact first FactRef and source version in the middle rule’s actually named inputs. At runtime only a successfully internally committed first step may publish a second signed return. Among the admitted cards rule 55 is solely a consumer. The real local reverse observation 55/op1→143 cannot continue: the source operation performs a Set and does not publish the required new `let` constructor FactRef. The NoAlias self-loop lacks a native consuming record and cannot seed a two-step default plan. No licensed two-hop path exists in this evidence; this says nothing about unexamined donor traces or additional runtime grammars.

## Reproduce

```sh
d=benchmarks/pass3-cell-gpu/ripsat-strict-programs
small="$EXP/compact-holdouts-20261121-v1"
python "$d/compile.py" --evidence benchmarks/pass3-cell-gpu/ripsat-donor-evidence/evidence.json \
  --donor dot-product="$small/dot-product-1703/program.json" \
  --donor jacobi-1d="$small/jacobi-1d-1703/program.json" \
  --target "$small/sum-bits-1703/program.json" --out "$EXP/sum-strict-ripsat.json"
python "$d/verify.py" "$EXP"
```

Checked-in compact native text and an unpacked immutable bundle both work. The Python entry is `compile_library(evidence, donors, target)`. The returned object pins `target_sha256`, evidence and trust digests, scoped native proofs, rejected candidates and the executable spec. An independent source and artifact-tampering suite exercises fail-closed behavior. [Adversarial acceptance tests](../ripsat-strict-acceptance/README.md)
