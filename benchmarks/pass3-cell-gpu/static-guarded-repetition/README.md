# Repeat an already wired constructor-return instruction

A bounded static variant may repeat its edge beyond depth two only when the same compiled instruction can produce a fresh fact of its own guarded input constructor. Depth is fixed before the external producer executes (2/4/8), and the rule and operation lookup for the next guarded consumer is compiled at setup. No unrelated cursor can become the next parent. Each release is gated by actual source Run, live version, actual return identity, local guard and normal publication semantics. No typed birth is credited twice. The grammar is extracted without rule names and happens to admit a useful decreasing SubTuple chain.

Three native inference samples per arm. At depths 0 / 2 / 4 / 8 the 3mm external packet counts were 558,074 / 542,857 / 542,826 / 542,800. The unchanged 92,658 final-visible origins give FEPT 0.166032 / 0.170686 / 0.170696 / 0.170704. The signed internal steps' final-visible typed origins at the three nonzero depths were 4,805 / 5,033 / 5,148. Each limit is run separately. A deeper template can displace a shallower ownership decision; counts across depths from different runs cannot be added. At depth eight, 75 commitments were real eighth-level releases with 145 distinct typed final-visible facts at that level.

One selected concrete 3mm root, serial 65,247 at Run 831, explicitly names cell 24,146 operation 2, version 826. The root produced three distinct visible typed facts. In Runs 835, 839, 843, 847, 851, 855, 859 and 863 the chain passed the actual SubTuple returned by operation 5 into the same guarded rule. Those eight applications contributed 23 additional distinct visible typed facts, exclusive of any independently paid child. witness.py chooses the most productive among deepest paths for illustration. Across **all** 542,800 paid packets, only 660 gained two or more internal typed final-visible facts. The global mean has the full denominator.

Sum-bits saturated this restricted action space at depth four, reaching 0.222765 from 0.212526. The 3mm medians for the fixed +264.11 MiB process RSS increment were 1,102.53 ms at depth zero and 1,172.56 ms at eight; sum-bits +9.27 MiB was 27.52 and 27.83 ms. Three independent processes per arm measured memory. This is a static program mechanism; RipSat discovery and trained variant selection require independent evidence.
