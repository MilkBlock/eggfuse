# Learn bounded cross-Run Cell paths one committed transition at a time

This experiment extends the [one-hop mixed integral issuer](../integral-filter-joint/README.md) inside the original Rust Cell CPU Pass 3 engine. The actor scores its unchanged source bank. The verifier may reconstruct a consumer from a published producer port and omit its external packet under the same scalar-negative and mixed-bank contracts.

Each path edge identifies the producer rule, output position, consumer rule and LHS pivot. The first actual source commit accepted by the one-hop verifier attaches a link to its real outgoing Cell cursor, including the original root, immediate model serial, rule, Run, depth and first edge. Only this previously committed cursor may supply a second hop on a later scheduled Run. The second computation independently executes the compiler-proved complete-key suffix from the now-visible output. A stale/unmatched parent, disconnected path, unsupported suffix or missing library entry retains ordinary execution. The bound is two transitions. The original engine wins ties and commits in order; this experiment creates no additional graph-visible stage.

An independently verified binding can still retain its original external packet. A candidate can also fail to win. Ranking uses only an actual external packet omitted by native issuance, followed by a real ordered commit whose root, immediate predecessor serial and route agree with the independent issuance proof. The verifier also records whether a credited second-hop packet followed a first-hop packet that was itself suppressed. A route's mere presence or later source usage gives it no Bake reward.

### Training and held-out controls

1. Run unrestricted depth one on dot-product and jacobi-1d. Accumulate the number of wire packets actually omitted and committed for each portable producer/output→consumer/pivot route. Select up to 32 positive-return routes, in decreasing count.
2. Rerun those same donors with only the selected first hops enabled, exploring second hops only through a successfully committed first-hop link. Select up to 32 connected extensions by their actual second-hop suppressed return. Each retains its admitted prefix.
3. Freeze the two libraries before running sum-bits or 3mm. A portable rule identity hashes the compiled query, effects, slots, interface, ruleset and seminaive flag. When an identity has no unique counterpart in the target, decline the route. The library contains no instance addresses, model scores, program-specific source witnesses or future Run outcomes. [Frozen library and donor receipts](library.json)

The native comparison includes all eligible first hops, all eligible first and second hops, the round-one donor library, and that same library plus round-two extensions. All four execute the same frozen base neural model, static-scalar filter, mixed packet issuer, allocator and source rules. The denominator includes each actual external single/multi root plus every selected nested child, including zero-birth packets. New/retained numerators come from actual token-attributed constructor fact registrations and their original identities at final export. Four rotated ordinary inference timings follow one warmup per workload. The timed binary charges the route-dispatch, local proof and detailed route counter work. Separate audits also recheck the complete selected bindings and terminal identity ledgers.

Every genuinely omitted second-hop packet on both programs was preceded by a *genuinely omitted first-hop packet* on the same original model root. The source checker authenticated the preceding child’s exact serial even when multiple siblings had equal-looking bindings. In the depth-one control the injected bad serial has no opportunity to affect a nested activation. With depth two, flipping the predecessor serial of the first otherwise verified nested winner aborts after 11 / 32 completed Runs.

The donor study selects 32 first-hop paths accounting for 3,657 actual saved packets on its donors. Only five connected second-hop paths had positive wire return in the second training round, totalling 163 additional packets. On both held-out programs 26 first paths and three extensions could be relinked exactly; only two extensions actually saw an eligible port on each. Against unrestricted depth two, the compact donor library recovers 4/253 and 427/5,280 second-hop omissions. Its restricted first-hop pool also omits only 315 / 13,600 packets against 1,115 / 22,946 unrestricted. The sum-bits/3mm library update saves four / 427 additional external packets yet increases recorded root wire by 32 / 1,784 bytes: mixing internal lanes can split external header spans. Packet and byte optimization have different payoffs here.

On 3mm, one recurring actual unrestricted path connects producer rule 249 output 2 to rule 502 pivot 0, then rule 502 output 6 to rule 506 pivot 0. Rule 249 is an always-run DoWhile/context rule; the terms rule 502 reads the resulting Const and emits PotentialExtractedExpr. The terms-helpers rule 506 consumes that exact published PotentialExtractedExpr and updates ExtractedExpr. This path yielded 372 verified second-hop commits and all 372 genuinely omitted consumer packets. The unrestricted second-hop checker opened 144,553 anchor rows (115,928 at depth one) and made 130,604 suffix lookups (106,245 at depth one). The corresponding costs with the limited library were 20,792 / 20,347 anchor opens and 16,084 / 15,885 suffix lookups. These are complete native runs under each library; the counts are not a replay reward or future-RHS prediction.

### Why the donor’s second round covers little

An independent held-out diagnostic freezes the round-one donor prefixes and allows **every** connected second hop below those prefixes. It actually suppresses only 6 / 501 second-hop packets. The donor-selected second-round extensions recover 4 / 427 of these. Most of the missing opportunity was already excluded by the first-round selection. In unrestricted held-out execution 136 / 3,167 distinct paying second-hop shapes produced 253 / 5,280 omitted packets. The 32 largest by retrospective held-out frequency account for 149 / 1,848 of those observations before enforcing any shared-prefix budget. This last number describes concentration in a recorded run and is not a deployed policy or rerun.

In the native source ledger, sum-bits has 312 second-hop source resumes and 3mm has 6,139. Both sets belong to actual singleton-owned rules. A one-consumer-per-activation architecture cannot remove more than that many additional packets at this depth, even granting every source resume an exact transferable prefix and preserving all other traffic. It would therefore cap final-visible nodes per external packet at **0.239519 / 0.175161** for these frozen frontiers. Unrestricted native depth two captures 253/312 and 5,280/6,139 of the optimistic second-hop ceilings. Source event ordinals reset within each Run; the diagnostic disambiguates the singleton/multi owner using the disjoint observed rule-provider sets and verifies the source graph and original neural winner hashes.
