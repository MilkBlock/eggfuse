# Independent named child generation with a disjoint ordinary residual

An external model token already names its actual source parents, static variant and exact producer operation. When that primary Cell actually creates the specified constructor it registers only its exact returned FactRef, version and future consumer. The simple seminaive unary consumer reads its RHS slots at statically known columns. After the original watermark, a live, unchanged, signed FactRef can supply its own binding even when other rows of that constructor table came from unrelated producers. The selector is the previously Baked static type variant in the original template word. No new model was trained to name more productive parent instances here.

At the original consumer Run, **the internal actor evaluates its own registered coordinates first**. It opens just those already signed FactRefs and fills their predetermined RHS inputs. It does not inspect ordinary candidate outputs, search a neighborhood, enumerate an e-class, select a convenient sibling, or look at a verified winner. A hidden, changed, retired, too-new or stale-watermark port does not activate. An approved depth-two path can register a second return only from the authentic, internally committed first child of that same external root.

The ordinary residual still incurs native work. After its original snapshot/watermark machinery supplies headers, it performs one source-address membership test per ordinary header. An exactly covered address is excluded before model feature evaluation, per-row scoring or packet formation. A matching address with an inconsistent version is an error. The remaining source addresses are scored and transmitted in contiguous external spans. The two independent lists are merged by their original ordered physical addresses. Logical model/root serial ranges include the signed positions, which serialize zero external bytes. The verifier constructs native binding records from the signed list even without looking at ordinary residual logits. It restores original ordering before source winner selection. For these eligible one-table occurrences, Spine restores ownership at known addresses for both lists. No generic Spine delta enumeration is used to discover a child.

Original recurrent state uses the all-fresh eligibility/count proof; internal rows contribute those counts with **zero child logits in normal execution**. An independent detailed audit recomputes their historical scores and rematches to the original source. The residual actor may still inspect metadata for already covered addresses to exclude them. Each exclusion, external score input, internal activation, span and direct Spine lookup is counted. Internal native records remain allocated and charged. [Build, corpus and frozen donor identities](manifest.json)

The arms share a single filtered native Cell CPU binary. The scalar omission pass stays on throughout. The general compiler permits every statically valid direct constructor-destructuring consumer at one or two hops. The donor controls use the frozen consumer schemas and compiler-completed producer operation sets from the previous study. They share the same producer-schema choices across their whole and partial controls. [Original filtered comparison](../filtered-explicit-parent/README.md)

Both workloads matched the independent default CPU on every Run's RHS inputs, ordered writes, union events, Spine and final graph. All arms also matched the learned control's original model scores, winning root/child source references, logical serials, physical IDs and complete birth and terminal-identity ledgers. The selected producer still carries its variant tag, so that wire's bit pattern can differ from the leaf control. Corrupting an otherwise valid signed operation index instead aborts the request.

## Trace format

With `strict_named.record_links=true`, a successful internal commit emits an audit tuple `[child serial, external root serial, static path, coordinate trail, child Run]`. Each path edge is `[producer rule, selected operation, child rule]`; each actual coordinate is `[Cell ID, operation, source epoch, producer Run]`. The first root was paid as an external packet and every coordinate comes from a real native constructor registration. In `signed_commits.json` records shared between arms appear once per workload. Each arm carries its ordered record indices. An appended six-element vector gives new/final-visible counts for typed constructors, separately generated runtime-dynamic constructors, and separately paid nested merge-child constructors, in that order. Zero values and zero-birth committed activations are retained.
