# Learn which externally issued producers carry a consumer-family right

The existing mixed integral path can replace an external consumer packet with an exact activation released from a previously accepted Spine root. A producer inside that lineage may itself have arrived via a real, independent model packet. This experiment lets the issuer give such a producer a one-hop family right. The right covers compiler-proven consumers of its actual future published ports on the original Run schedule. An internally synthesized result cannot create a new paid right. This makes the origin of the authority checkable when there are siblings or several consecutive opportunities.

The issuer sets one bit in the existing template word of an external singleton page or typed multi-parent header **before verification**. Individual candidates retain their source identity and count as individual emitted packets. Decoding separates the bit and template ID. The original verifier must accept the actual root before the issued serial, producer rule, original root owner and source Run can be attached to that live producer cursor. On the later Run the child checker validates that exact predecessor, current visible source row, ordered compiler-proven complete keys and computed slots. The local eligible consumer then competes in the existing mixed ordered arbitration. A wrong predecessor is an error. Internal fallback records use an unmarked template; an internal delivery can neither authorize itself nor recursively manufacture a paid grant.

## Frozen learning procedure

Two source-separated donor programs, dot-product and jacobi-1d, execute the same native model with all external source types permitted. At true commits, count the additional internal children associated with each structural producer schema and the tagged live producers available to publish a right. A sparse one-hot action-value model stores the smoothed return `committed_children / (installed_live_producers + 4)`. A value of at least 0.01 selects the family. Because an aligned execution must retain the same constructor numerator, saving a real external child packet directly improves the packet-yield objective. This reward does not optimize CPU latency. No held-out activations, stage schedules or final graph enter the fit.

The donors supply 224 and 1,237 actual additional committed children. Eight producer schemas pass the threshold and seven are present in each held-out compiled program. Keys hash the query, effects, slots and interface of a compiled rule. At deployment the compiler maps the eight learnt schemas to the target rule directory. The per-packet option is a policy lookup, not a new large neural model or an additional neural inference over every live graph node. The original actor weights, logits and recurrence remain frozen. The two workload pairs are 3,610 / 2,691 and 119,503 / 92,658. All externally issued roots and selected nested child packets count, even those with no birth. All 305 / 7,120 child decisions are available separately. Values from the all-tag arm are an executable comparator, not an oracle upper bound: changing which consumers are external can itself change which future producers have a paid right.

The trained gate marked 1,001 / 29,457 external roots. From 436 / 13,805 accepted tagged producers, 409 / 13,199 carried the right through a live resumed cursor. There were 651 / 29,746 later scheduled anchor visits to those rights, yielding 233 / 8,214 independently validated extra internal bindings. Every one reached its actual ordered RHS. Charging one separate output packet for every marked producer, instead of using the bit physically carried in the original token, would yield only **0.218514 / 0.166540** final-visible nodes per packet. This alternate denominator reverses the direction of the improvement. Grouping a page of candidates as a single model output is never used for the headline.

The 3mm donor gate saves 8,214 external packets and 197,584 original root-wire bytes against the prior mixed control. The all-producer alternative saves only 29 additional packets while marking 524,377 external roots. Relative to the prior mixed control, release-side suffix lookups rise from 106,245 to 124,361, singleton verifier point lookups fall from 356,877 to 355,591, and regular singleton verifications fall from 311,648 to 303,434. On sum-bits the corresponding suffix reads rise from 2,635 to 3,015, point lookups fall from 5,811 to 5,746 and regular verifications fall from 5,444 to 5,211. The trained gate costs 0.33 / 27.29 ms in complete inference medians. The matching prepared request walls are 67.24 → 73.91 ms and 2,223.20 → 2,282.06 ms. All times use four rotated post-warmup samples on one host.
