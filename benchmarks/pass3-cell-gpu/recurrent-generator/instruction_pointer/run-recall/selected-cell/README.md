# 已选 Cell 的静态字段读取与混合入口训练

本轮在实际 CCP v0.1 Native Runtime 上完成。静态字段投影解决了已知接口上再次猜字段的问题。混合入口的主要类型错误发生得更早，模型选了当前没有对应类型证据的入口，或选错了 owner。保持相同权重，仅约束父角色的静态类型，已能改变独立执行的 Coverage。额外训练可以推动不同有效计算，但两种新课程都未稳定兼顾零父和双父计算。

## 接口与对照

原来的模板优先解码仍是基线。为保证直接读取只发生在模型选出的具体 Cell 上，本轮额外比较一种完整 Token 概率分解。先将旧读出中同一根规则的模板概率相加，抽取入口规则；由现有地址网络选择该规则的首个具名引用，联合选择 owner 与端口；再在共享这个入口的 Primitive 和 Higher 中选择具体结构，最后生成其余父引用。零父规则直接从入口概率发出。首父之前的入口分数仍使用整份 Memory 的神经上下文，此时不做操作数字段读取。训练与抽样使用相同分解，监督均为完整 Token CE。

同一分解内的 soft 组和 direct 组读取相同的已选端口。direct 在表身份一致、两列均可由原有 Recipe 拷贝及具名接线静态追溯时，按布局映射取出字段。其他结构复用已选端口上的软读取。列投影没有学习参数；Value 投影、关系运算的可训练残差和最终读出仍接收 CE 梯度。沿用原 GNN、整体 KV 和已有的 8,576 个可训练参数，仅对已签发 Higher 的确定内部接线进行原生接续。[模型](../../selected_cell_model.py)

typed 组在网络选定模板或入口规则之后，按该父槽声明的表类型归一化原有神经地址分布。它会读全部公开端口的表标签并为寻址付费。空域消耗本次槽位，既不重抽其它入口，也不由宿主补充证据。字段值、guard、dirty、版本比较、未来回执和其他角色的可完成性均不参与该约束。所有正式组共享原有调度窗口、六槽预算和固定 Seal；原生验证器负责判断实际请求。下述离线概率审计与正式计时分开执行。

## 复现并归因上一轮的 type

对上轮原样重放 3 组数值 × 2 种接线 × 2 个生成/地址种子 × 2 个训练种子。每个模型的最终事实图摘要、计费分类和有效操作与历史记录一致。通过 CCP 的具名请求 ID 对照每条回复和生成时可见的版本。在同一窗口内立即 Submit，然后才 Seal。Rust 的 proof 准入先检查触发，具名引用解析后依次检查退役、隐藏、表类型、版本与绑定。下表仅归因实际收到的 type；这批运行所有内部后缀的 type 余额均为零。[准入](../../../../../../engine/cell-runtime/src/token_transaction.rs) · [具名读取](../../../../../../engine/cell-runtime/src/cell_tokens.rs)

|---|---:|---:|---:|---:|---:|---:|

两组的实际 type 全部发生在角色 0。version 回复均为 0；原生按顺序检查，表类型不符时没有核验后续版本或 guard。另有 129、96 枚静态类型不相容的 Token 先收到 untriggered_rule，保留该实际回复。所需表缺席意味着当前已选入口无法完成；对存在同类型端口的情况，仅能定位到已生成的模板与引用组合，不能由一条回执推断应该改选哪一个模板。概率质量按各自主状态中有模板的窗口等权计算。[逐种子审计](historical-audit.csv)

## 静态字段能否正式用于计算

沿用旧单入口检查点，在新的五列声明中移动操作数，两个冻结种子分别对 16 对接线冲突状态进行盲测。每对固定真实入口、只改变 Recipe，要求两个正确 Higher 同时排名第一。soft 两种子各 8/16，direct 各 **16/16**。平均正确完整 Token 概率为 51.0% 和 78.4%；实际从完整 Memory 独立执行时，两者平均 Coverage 为 85.94% 和 100%。未给策略提供正确入口，单入口小环境中恰好只有一个 owner。直接投影 Value 与关系张量上的完整 CE 平均梯度范数分别为 .153/.100 和 .155/.102。[字段盲测](projection.csv) · [梯度](gradients.csv)

## 混合课程与抽象层级的竞争

从各自相同的上轮混合检查点出发，每种课程、每个种子均追加 420 次 AdamW 更新。每步从一次完整原生重放中取入口及后续已发布状态各一个，每个状态抽取八枚真实具名目标，共 6,720 次完整 Token 曝光。轨迹中的 Primitive、Higher 与连续发布状态共享单一 CE。曝光含重复采样。固定退出和每页槽数沿用上轮。

* mixed 只训练原多入口分布。curriculum 使用单入口、多入口、多父数三个来源，三个连续阶段采样权重分别为 (6,3,1)、(3,4,3)、(2,3,5)。每个来源含十二个程序。多父数同时增加了无需引用的 StartMark 和可生成四条不同事实的双父 Together。该双父根的两种输入类型不同，所有笛卡尔组合均合法；网络只生成单个具名绑定。
* diverse 进一步纳入原生分支汇合程序。一个后继同时消费前一层结果和此前 Mid 的已签名输出，末端还需独立 Permit 证据，包含真正的跨父共享变量约束。四来源权重为 (12,6,1,1)、(6,6,4,4)、(4,4,6,6)。训练中使用两种较浅结构，盲测使用新的数值、随机具名地址及较深 Higher。对扩展集核对 Bake 规范结构签名与当前课程语料分离。每个种子保留训练曲线、实际来源曝光和权重。前代 GNN 的全部历史训练分布未在此重新审计。

| 完整自主执行 | 冻结 direct+typed | 仅追加 mixed 训练 | 混合课程 curriculum |
|---|---:|---:|---:|
| 单入口 Coverage | 100% | 100% | 100% |
| 多入口 Coverage / EPT / EPS | 53.85% / .426 / 614 | 59.13% / .439 / 655 | **62.74% / .457 / 691** |
| 零、一、二父混合 Coverage / EPT / EPS | 15.73% / .304 / 234 | 14.11% / .283 / 213 | **40.12% / .477 / 535** |

多父数盲测 16 次独立执行中，冻结模型得到 16 条零父 StartMark，零条双父 Together。curriculum 得到 **0 条 StartMark、24 条 Together**。固定入口处零父规则的平均概率从 76.92% 降至 8.66%，16 次均未实际签发；双父规则的平均概率从 0.79% 升至 24.96%。平均每次运行签发 22.69 枚神经 Token，预算为 42 槽，完成 1 个 Higher。原 64 对基础接线冲突测试，两种种子在每次训练后均全部保留。单入口能力可以保持，但同一页内的计算竞争仍然会使整个类别被漏掉。[按事实与签发拆分](arity-choices.csv) · [保留测试](retention.csv)

相同预算的 diverse 在多父数组获 45.16% Coverage，零父和双父分别产生 10 条与 6 条事实；分支汇合组从 73.07%/.311/521 提高到 76.79%/.320/534。普通多入口组从 62.74% 降至 58.89%。这些实验同时改变了语料采样比例及结构多样性。Coverage 和 EPS 的增减不能单独归功于看见了一种新拓扑。[分拓扑逐种子结果](topology.csv)

## 验收与复现

Coverage 使用实际终图中的参考关系行；EPT 使用原生有效操作除以实际付费请求，EPS 包含单线程 CPU 神经读取、抽样、通信、运行及发布墙钟。正反序重复核对事实、终图、付费请求分类、全部回复分类及有效操作一致。同终图配对数较小的项不据以推断速度。Teacher、穷举概率审计、按真实输出核对与离线标签仅用于训练与诊断。当前证据限于受控原生程序；多父数中仍有整类必要事实被漏掉，尚未达到重新验收开放 EggCC 的条件。

沿用上一轮 interface-role 的 ARTIFACT_ROOT、CELL_DATA、CELL_COMPILER、CELL_REPLAY、PYTHON，并在 instruction_pointer 目录执行。原始运行记录位于 PARTNER_INDEX_OUT/selected-cell，包含具名引用、请求 ID、状态、终图与事实、权重、课程记录及证据摘要。所有计时均使用实际 Rust Runtime，本轮无协议或生产调度改动。

```sh
export PARTNER_INDEX_OUT="$ARTIFACT_ROOT/conditional-value"
sh selected_cell_reproduce.sh
"$PYTHON" -m unittest test_selected_cell test_interface_role test_operand_read test_value_read test_compatibility test_cell_kv test_token_embedding
```
