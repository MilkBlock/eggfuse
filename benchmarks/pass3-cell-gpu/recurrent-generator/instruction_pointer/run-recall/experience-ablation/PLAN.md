# 统一计算经验的质量消融

目标是提高预算内不同有效计算的发现数以及多程序独立执行的 Coverage、EPT、EPS。网络、寻址、CCP v0.1 和训练目标冻结。六类经验共用生成网络，原生签名标识一次计算，签发 ID 标识一次请求，原子效果按原生账本归属。一次决策以当时的发布快照、同 Run 已收回执及剩余生成预算标识。跨发布事件须另开记录。未核验、待发布及因预算无法尝试的分支保留未知。

| 顺序 | 唯一研究变量 | 对照与验收 |
|---|---|---|
| P0 | 经验记录与历史基线 | 从原生证书和记录复核事实覆盖、付费、有效操作、完整槽位欠额及 575 的首次遗漏。因子化随机始终保留。 |
| P1 | 训练状态来源 × 已核验遗漏 | 纯 Teacher、Teacher 加自主；各自比较只用实际贡献与补充同状态遗漏。每对有无遗漏组使用相同状态、随机顺序及更新预算。 |
| P2 | 重复与失败反馈 | 同一批自主状态，分别开放重复监督、原生失败监督及两者。分开统计重复生成、签发、结果和检索，核算生成欠额。 |
| P3 | Shuffle | 从同一前缀重放合法重排、已执行子集及事务边界，对比等量原始片段；重新核验每条变化后的轨迹。 |
| P4 | 长程贡献 | 保留相同轨迹，切换即时／延迟标签；移除或推迟指定请求并允许合法替代证明，按每个独立效果分摊归属。 |
| P5 | Higher 替代 | 在相同边界核验 Primitive／Higher 的实际效果和成本，按结构签名留出，仅计已执行步骤。 |

先按程序和完整轨迹划分。涉及新布局的 P3 与 P5 额外按规范化接线签名划分，再做增强。P1 沿用冻结目录，允许程序共享 Recipe。训练使用 sum、dot、训练 grammar。fact、loopfact、sum-divisors、留出 grammar 用于评估。经验按六类来源交叉标注，复用同一快照、请求和效果记录。每类报告独立状态、签名、程序、真实执行数量和核验成本。

第一批执行 P0、P1。对自主轨迹保留每页生成、签发和实际反馈，覆盖首次停产、高重复和普通 Run。先分析每 Run 第一次生成决策，后续页保留为经验记录。原生离线分叉只将同一快照可启动、在实际已执行请求之后仍带来新增效果的计算计入遗漏。其他等价计算得到的贡献须扣除。不得将未来信息馈入 Query。

主要检验自主状态的 64、256 枚完整 Token 预算，同时报告 4、16 和完整原生独立执行成绩。重复训练种子及配对生成种子，记录同终图或相近覆盖下的实际时间。未稳定超过因子化随机则保留失败结果，后续阶段仍按各自的研究门槛决定是否启动。

## 数据生产和优先级

P0 首先对同一原生回执建立三个可追溯的标识，即生成时的决策及发布版本、签发后的 Request ID 和实际生效的原子操作归属。按 Run 核对生成槽位、完整 Token、基础签发、Higher 续接和所有原生回执。单列未填预算和未获调用的页。随机基线使用相同发布状态、静态类型域和完整 Token 预算。线上看不到离线审计列。

P1 同时检验状态分布和标签分布。训练时固定地址网络、旧 GNN、AdamW、256 次更新以及 4/16/64/256 的预算分布。混合组替换一半 Teacher 抽样位置；同一来源内有无遗漏两组复用相同决策状态和训练种子。原始状态中未探索的替代路径保留 Unknown。对同一快照先原样重放，再追加已由原生确认可启动的请求。实际贡献已经被其他请求覆盖的部分按原生账本扣除。主要读数取自主快照预算 64 和 256，配对到相同数量的完整 Token。三个训练种子、两个冻结抽样种子，四个程序独立跑完。冷启动墙钟按首个种子正反序复测。

P2 复用同一批自主经验，做「重复反馈开/关 × 真实失败反馈开/关」的配对实验。分别识别物理重复生成、重复签发、结果重合与重复搜索，待发布和合法但无当期产出的请求保留待定。对 dirty、binding 和 guard 三种已核实失败记录当时的状态。检查减少失败的同时是否减少了完整签发，是否增加了不同有效计算。

P3 先测试合法拓扑重排和随机已完成子集，每次只改变一个增强因素。与等量重采原轨迹对照，按新轨迹原生重放。报告实际新增的状态、不同合法后继集合和程序数；彼此相同的训练片段只计一次多样性。P4 固定同一批轨迹，对比仅即时贡献和有限时间窗的延迟贡献。推迟目标计算并允许合法替代路径恢复。共同解锁的最终效果只分摊一次，未证实的因果贡献保持未知。

P5 在原子生成达到对照门槛后进入。使用训练侧的 Primitive/Higher 等效重放，核对可见事实、版本、跨发布消费及付费数。训练冻结后再提供结构留出的 Higher，并分别测量自主选择、绑定和完整执行。每个阶段先单独比较新增标签的边际效果，再对胜出组合做移除单项的复核。

每轮优先报告独立状态数、实际签发数、已验证的新计算、未知比例和新增来源的覆盖范围。晋级需要在两个主要自主快照预算下稳定超过因子化随机，并在留出 EggCC 独立执行中保持 Coverage，才进一步讨论同终图的 EPT 或 EPS 收益。局部平均值和较低覆盖下的高吞吐均单列记录。
