# 完整 Cell Token 的生成吞吐审计

在 fact 的相同种子 536 上重跑 CCP v0.1，完整复现了初始模型和上轮双 Credit 模型各自的终图、有效操作、付费数和原生回执分布。两条自主轨迹会到达不同状态，因此另外用相同冻结状态和随机数做了模型对照。

## Loss 实际监督了什么

保持原模型、数据、优化器和训练种子一致，从同一初始权重分别只启用自身正例、遗漏正例、失活模板罚项、完整绑定失败罚项、跨状态已完成对照、单父替换。另训移除失活罚项的联合组，并重放原联合组。两个种子重放后的参数最大绝对误差均小于 5×10⁻⁷。控制 Credit 的计算参数更新为零。

- 上轮发现损失只对原生可归因的有效结果分组，以完整路径概率训练。遗漏正例同样进入这些分组。失败池内的 guard、版本失败等可以出现在打分批次里，进入批次本身不产生负监督。
- untriggered_rule 的实际罚项为本页样本中失活、且生成和签发时已核实的每个不同模板加一次模板概率。516 次带此罚项的更新中，420 次该页没有直接计算正例，413 次调度集合中所有规则均失活，297 次只罚了调度集合的一部分。上述计数有重叠。模型仍必须选择一个模板，因此降低某些叶子的概率会改变其他叶子的质量，包括没有完整绑定训练记录的叶子。这是基于采样目标与实测行为的解释。
- 完整绑定失败项在该项中截断模板概率的梯度；单父替换直接对已核验的相同前缀伙伴排序。模板和父寻址仍共享参数。在 58 个冻结起点各取 256 个相同噪声槽，单独训练绑定失败就改变了 39.7% 的模板选择，单父替换改变 12.9%，单独训练失活罚项改变 83.6%。投影门使用冻结权重，DFM 编辑器、控制器均未参与此训练。
- 已完成对照在不同真实状态下比较同一 Token 的路径概率。没有全局惩罚相同物理地址。在本次重放中未发现将 Unknown 直接当负例的路径；完整训练输入本身缺少失败于成形之前的槽。对未核验组合的概率仍会因归一化和共享参数间接变化。

## 140 万枚经验与优化器曝光

累计 1,403,990 枚是历史全程自主签发量。上轮只从 64 个训练程序的 2,874 页取样：全程自主来源 122,448 枚，含辅助前缀的来源中另有神经签发 156,279 枚。这个可用池含 45,817 条遗漏记录。优化器按状态和具名路径抽样，不能把整个池计作一次训练曝光。

## 未签发行为的经验格式

可选的 --record-slot-attempts 在已有批量读回中记录每槽的模板、失败父深度、原因及成功前缀的具名 owner/op/version。状态、Run、策略权重、真实 Response 和签发序号沿用同一 shard。失败原因编码为 1 + 3 × 零起始父深度 + 类别，类别 0/1/2 分别对应空表、投影缺失、表类型不匹配；0 表示完整构造。无签发槽的价值监督掩码为假。该字段用于后续与具体的原生遗漏或替换见证关联。本轮只回放一个已有的 24 窗口采集实例验格式，逐项核对签发、回执、贡献和遗漏；数据规模没有扩张。正式性能测试关闭此观察器。[经验采集器](../../credit_scale_buffer.py) · [观察器](../../throughput_slots.py) · [复现命令](reproduce.sh)

## 同一冻结状态、同一随机数

四个工作负载，共 58 个起点，来自 Teacher 轨迹或独立 rollout。每个程序和轨迹来源从既有快照按 Run 等距取至多 8 个。恢复 rollout 的真实最近 Response 和上下文，核对 Query 张量完全相同。冻结诊断用训练种子 9633、两个生成种子和相同的 64 槽物理波；每波在同一地址域用相同随机数。冻结实验各组都执行到 1,024 槽，从同一序列取前缀。在线独立执行仍使用原 16 槽页及原生终止规则。两种场景的成形率应分别解读。

固定 64、256、1,024 槽时，初始模型平均累计发现 1.16、2.32、3.67 个不同有效计算，上轮模型为 0.25、0.58、1.34 个。以完整 16 枚为条件，保留五个主要对照均能在槽上限内达到目标的 98 对状态与生成种子；全部试验为 116 对。初始模型原生接受率 5.74%，上轮模型 4.21%；两组分别签发 1,568 枚根请求，其中具有有效操作的请求为 83 和 59 枚。每枚有贡献请求的采样墙钟从 12.36 ms 增到 25.75 ms。计时包含组页、Metal 波、读回及解码，计入最后一波全部开销，离线核验单列。相同完整预算下，新模型在 16 对上未凑满，初始模型为 2 对。所有未达预算的结果保留在 all 行中。冻结诊断的一部分与其他诊断重叠，计时为本机实际测量，不能解释为孤立 kernel 延迟。[逐预算与分来源指标](paired.csv)

## 恢复对照及验收范围

预先设置两个恢复对照。一组沿用原训练预算，移除失活模板罚项；另一组取初始权重加上原联合模型参数位移的 1/16，固定这个系数测试两个种子，未在留出覆盖率上挑选系数。前者检验归因，后者检验缩小更新能否保护原能力。fact 种子 536 上，失活项消融用 34,240 个槽、付费 6,346 次，约 5.40 槽/请求；1/16 更新用 23,744 个槽、付费 7,364 次，约 3.22 槽/请求。初始与上轮模型分别为 3.13 和 34.32。该种子的恢复组覆盖 94 个事实，初始为 113 个。训练部署仍沿用冻结初始权重和固定退出。
