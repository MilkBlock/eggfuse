分离状态和目标多样性的补充对照选定同样的 32 个训练程序，每个程序固定抽取 2 或 8 个真实状态，每个状态固定开放 4、16 或 64 个核验具名目标。各组均为 625 次更新，每次 16 枚，池内均匀抽样。比较同为 4,096 个可用具名目标的 64×64 与 256×16，也可在 256 个状态下比较每状态 4 与 16 个目标。该组独立于超参数筛选。
