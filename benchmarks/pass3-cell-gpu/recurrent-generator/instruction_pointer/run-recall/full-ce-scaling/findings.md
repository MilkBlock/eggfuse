# 端到端预训练与夜间消融结论

在当前原生语料与固定生成策略下，扩大完整 Cell CE 曝光能够改善部分基础能力。内部验证锁定的策略在 sum-divisors 上仍然落后于因子化随机。两枚训练种子和两枚生成种子的结果均保留。

逐条重放 1,050 条原生归档，覆盖 1,624,623 次生成请求。主池含 701 个程序、7,638 个不同决策状态与 538,107 个不同状态 × 完整具名目标。经验没有提供完整效果身份时保留未知。3,976 条空分支与单请求反事实中，EggCC fact 的 277 个可证明有贡献的具名目标合并为 131 个不同的状态 × 效果。

本轮有 70 条配置与训练种子组合、98 个经原生验证的检查点，其中 70 个在 10K、18 个在 30K、10 个在 100K。每条训练轨迹只取最高档后，优化器实际曝光合计 1,760,000 枚完整 Token，训练进程计时合计 8.09 小时；多进程并行，单模型曝光上限为 100K。短筛仅有一个种子的配置不作跨种子稳定性结论。共保存 3,540 条预算运行，其中 130 条为外层自主评估、50 条为离线调度干预。另有 40 次串行交替计时。

## 哪些变化可重复

- **采样方式。** 冻结获选权重，在 loopfact 上按五个预算和两枚生成种子平均，页内完整具名 Token 不放回在 7 个温度 × 2 枚训练种子的 14 个对照中都提高了 Coverage。温度 1.0 下，种子 71 从 4.469% 提高至 4.667%，种子 113 从 4.460% 提高至 4.676%。两个种子的最高 Coverage 分别出现在温度 2.0 和 1.25。温度变化只在内部程序比较，正式外层用原温度。
- **优化器。** 10K 单种子中，半批量、裁剪 0.5/1/5、2× LR、若干数据采样均有验证 CE 降低而三程序平均预算 Coverage 未改善的实例。半批量、中心、2×、4× 批量分别进行 468、252、126、63 次更新，状态与具名目标集合相同。4× LR 在 10K 初筛表现较好，30K 双种子稳健排序落至八组末位。零权重衰减下，Adam 与 AdamW 中心对照训练后的 51 个保存张量逐一相等。
- **训练数据。** 在同一批实际签发的有效目标上，按轨迹频率抽样在 loopfact 的双种子 10K 预算平均 Coverage 达 4.66% / 4.69%，状态均衡为 4.46% / 4.60%。反事实效果均衡相对具名目标均衡，一枚种子提高，另一枚略降。在相同 32 个训练程序、4,096 个可用目标、625 次更新条件下，64 个状态每状态 64 个目标与 256 个状态每状态 16 个目标也没有一致胜者。程序数、状态数、目标数和重复曝光需要分别解释。
- **课程。** 单种子初筛的自适应课程比中心多用了更新次数。配平到 625 次更新、每次 16 枚后，保留基础样本的课程在 loopfact 两种子均高于严格小到大；进一步自适应调整没有稳定超过固定保留。正式自适应课程只读取训练状态来调节比例。
- **基础能力的短期退化。** 在同一批验证状态，继承初始化的 Higher 完整目标自由生成命中为 37.50%。Decoder LR 0.004、编码器倍率 0.1 的训练种子 113 在 10K 降到 4.69%，30K 恢复到 51.56%；种子 71 同两档为 40.63% 和 56.25%。这是一例可复核的早期退化与后期恢复。零父探针在上述 100K 参数组均保持 100%。
- **泛化。** 继承权重曾见过原定的两个基础验证程序，初测记录单独归档。正式选模使用重新生成并原生核验的两个完整程序和 loopfact。sum-divisors 仅在本轮配置锁定后运行。历史权重更早的全部预训练经历无法完整追溯，单个外层程序也不足以外推到所有 EggCC 任务。

## 为什么停在 100K

锁定的局部模型从 30K 到 100K 时，两个训练种子在三个内部程序的平均 Coverage 都提高。单看 loopfact，种子 71 从 4.379% 升至 4.667%，种子 113 从 4.703% 略降至 4.676%。这个微小回退触及预设的双种子晋级条件。250K、500K、1M 和可选宽度消融均未运行，当前结果无法确定 1M 曝光或其他模型宽度的能力上限。

## 剩余计算价值

在 sum-divisors 的 256 枚实付预算下，规则 375 的首请求为局部模型和因子化随机都贡献了 199 个有效原子操作。局部模型之后的 255 枚请求合计仅贡献 24–35 个有效操作，随机对照贡献 49–50 个。首请求后的持续发现能力解释了两者相当一部分效率差距。零请求固定调度的最终参考事实数为 0。

离线只跳过所有可构造入口均已核验失活的窗口，局部模型种子 113 在两个生成种子上分别实付 202、210 枚请求并覆盖 166、162 个事实；正式固定生成时均付 256 枚，只覆盖 119、118 个。这项干预改变了后续轨迹，也没有耗尽指定付费预算，单列为调度诊断。

下一笔计算预算优先用于规则 375 完成后模型与随机分歧的真实自主状态。配对核验同窗口的不同后续新增效果、构造完整 Token 训练目标，再以首请求后的不同贡献与完整预算曲线独立验收。当前结果支持保留冻结生产策略。
