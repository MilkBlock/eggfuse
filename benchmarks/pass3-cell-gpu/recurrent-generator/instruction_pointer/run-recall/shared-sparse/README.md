A builds the frozen joint projection on a selected Recipe edge, with the historical fallback decoder on other shapes. B scores physical pages then rows. Bcompact points its row views at packed page storage. C puts each published field through the frozen four-head map with deterministic reduction and rescales each coordinate to 64 intervals. Each field writes two weighted postings per head. A static wire selects the source and destination field positions. Channel sampling uses query weight times bucket mass, followed by a weighted posting draw. Eight proposals with replacement and 5% uniform exploration preserve access to all rows. A neural row prior and the sum of log soft-overlap scores across wires rerank the *same* proposed row. An unbound first role samples physical rows. C-anchor additionally probes random rows from one statically connected subsequent role and queries the same postings in reverse. Neither version computes a conjunction or scans a posting list for matching raw fields. The host handles named references, type-domain membership, physical rebuilding, and static Recipe wiring. Recipe selection in this experiment still scores the scheduled catalog.

**Diagnosis.** In 349 multi-page verified role decisions, B puts mean .1828 probability on the correct page (size prior .1788). Mean probability on the target row conditional on that page is .3842, end-to-end .0859. In 238 non-singleton wired decisions the dense row decoder gives .6304, dense field scores alone .6499, row MLP alone .0746 and normalized sparse field similarity under the same MLP/temperature .6981. For 208 non-singleton first-role decisions B gives .1096 versus .1087 uniform. These are conditional physical-target diagnostics with verified prefixes, not independent Coverage or complete productive-set mass. [Per-decision records](diagnosis.csv).

On the 1,024-row same-type hard domain every distractor shares one field. A produced 512/512 valid complete draws; B, C and C-anchor produced zero. Given the correct first row C offered a true partner in 12/512 draws and selected it 10 times. With eight valid partners, C offered one in 80/512 and selected one 74 times. The main conditional loss occurs in proposal formation. The shared implementation preserves row identity, but a bounded union of single-field proposals does not reproduce a selective joint proposal. **Unified memory accounting.** For one typed bank let N be rows, F total actual fields, W maximum row width, P pages. C feature bytes are 128N + 32F (32 float row features and four int32 lower bins plus four float32 fractions per field). Index bytes are 8(N+1) for row offsets, 4(264W+1) for channel starts, 8(8F+1) for integer cumulative masses and 4×8F for row ordinals. Named versions and physical lookup maps reside on host. B features occupy 2(128N+352F) bytes, Bcompact occupies 128N+352F. Both additionally retain 128P bytes of page means and any query caches. A materializes role banks and a conditional edge index on demand. Its postings alone occupy 384n+8 bytes for a single edge with n partner rows. Multiply only by concurrently materialized edges. The report splits features, index, caches, Recipe tensors, raw published payload, host objects and shared weights. Device storage uses unique backing allocations. MPS temporary figures sample allocator-visible high water at dispatch boundaries; driver scratch, whole-process RSS and opaque Rust heap are outside that metric. CCP payload uses six i64 per row and one u64 per field. [Full cost sweep](cost.csv).

At 1,024 rows with four fields, B/Bcompact/C feature+index+cache consume 3,154,048 / 1,581,184 / 667,796 bytes. C encodes a changed field once, but a single updated row rebuilds its typed table. At 4,096 rows this cost about 52.6 ms versus 1.6 ms for B. With 256 rows and four fields, C keeps 170,132 feature+index bytes across 1–256 Recipes while its Recipe tensors grow from 512 to 98,432 bytes. Three parent roles can reuse those same tensors. Version replacement, retirement, table movement, ragged rows, numerical sampling and catalog insertion have regression tests. Bcompact reproduced B's facts, entire graph, counters and receipts at both paired seeds. C's batched implementation also avoids B's per-slot host readbacks. For eight two-parent draws at 1,024 rows, C alone took 30.34 ms when dispatched one at a time and 3.52 ms together. EPS gains combine addressing and batching effects; none reflect new training.
