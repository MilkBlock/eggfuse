# 真实 EggCC 上的完整 Cell 联合生成

给定正确 Recipe，两遍全目标训练的三父分叉得到 20、21 次有新增贡献的签发，上轮为 12、13 次（各 144 次尝试）。在完全自主的真实 EggCC 执行中，训练改善了部分完整绑定，三个程序仍未取得一致的 Coverage–EPT–EPS 优势。

## 逐目标审计

三父旧语料有 32 枚有贡献的具名 Token，来自三个程序、九个「窗口 × 规则」。固定原生决策状态、版本、目标和 Primitive 目录，分别比较启用关联读取的初始模型与两份旧训练权重。对种子 71，完整概率下降的 30 枚中，29 枚最大损失在 Recipe，1 枚在第二父。对种子 113，下降的 24 枚都在 Recipe 处损失最大。平均到全部 32 个目标，种子 71 的四项 log 概率变化为 −2.19、+0.02、+0.35、+0.50。种子 113 为 −0.99、+0.02、+0.36、+0.44。

例如 fact 的 Run 6，规则 532 的具名父引用为 `(1,64,1), (-219,0,0), (-197,0,0)`。种子 71 的 Recipe 概率从 30.09% 降到 6.45%，三个正确父引用的条件概率分别从 9.28%、36.39%、30.17% 升至 14.33%、49.25%、51.21%。完整 log 概率仍从 −5.787 降至 −6.061。在 fact 和 loopfact 的 532/534 窗口，种子 71 的增量概率最大接收者都是规则 553，种子 113 则分别是 548 和 551。窗口审计仅标识已知可贡献的规则，不能把未标注的竞争者当作错误。[同窗口概率转移](root-competition.json)

逐目标表保留训练前后四项概率、自然对数差和完整 log 概率。历史存档由完整概率除以父概率乘积还原 Recipe 概率；新测量直接读取各因子并与完整 CE 核对。诊断目录中的每个家族仅有一个变体。正式混合目录还包含首父条件下的变体概率。[逐目标对照](triple-targets.csv)

原关联读出只从已选父投影静态连线。实验性反馈在三父及更高父数的地址阶段，用现有 GNN 操作数节点和当前上下文对尚未绑定的、静态相连的角色域做神经加权汇聚，再让当前候选行的共享字段投影读取它。每个候选行和未来域各线性访问一次，每个状态内按规则及角色缓存汇聚项；没有生成候选组合。该汇聚保留有限的域信息，多个伙伴的表示可能相互抵消。训练仍更新既有 4,160 个参数。对同一份反馈权重撤掉反馈消息，32 枚三父目标中打开消息分别有 23 和 27 枚完整概率上升，平均 log 概率增加 0.109 和 0.190。两个种子各自的 92 条反馈消息中，90 条有非零的完整 CE 梯度。[反馈路径与冻结干预](future-probes.jsonl)

## 数据与训练

- **准确重放**。三个 Teacher 和三个纯自主归档逐请求核对程序 SHA、请求 ID、原生回执和终图 SHA。以每批最多 16 枚请求构造 Submit 前状态，读取真实公开引用、版本、该规则自身的 dirty / watermark 和已经返回的回执。Teacher 与自主分别产生 415 和 32 条带正例的状态记录、2,690 和 36 次有原生操作归属的目标。超过 2,500 个公开端口或 2,048 行回执的批次仍重放，训练样本不包含这些批次。sum-divisors Teacher 有 15,631 个请求落在这个范围外。批内原生贡献的归属有顺序性，不能把这些数解释成各请求独立的反事实收益。
- **原生分叉与基础样本**。复用上轮 34 个真实自主状态、228 个原生核验目标。保留 12 个包含共享输入、一父与二父入口、值相等与不相等、Primitive 与多个 Higher 的原生训练环境。重新读取规则状态并与已有已核验快照核对。每折这部分有 666 个目标出现。EggCC Teacher 新增语料的标签是 Primitive，正式运行仍提供原有 Higher 目录。
- **历史 Replay**。从既有动态库按文件顺序取前 32 个纯自主分支程序。重新向当前原生 Runtime 签发全部 103,262 枚请求，逐帧核对发布、客观规则状态、具名回执、终图摘要和 origin 台账，再重建当前 KV，弃用旧策略的上下文向量和旧策略概率。共 103,262 次实际生成并签发、256 个带目标状态、4,492 个有原生操作归属的具名目标及 9,655 个经稳定追加分叉核验的遗漏目标。追加分叉要求原有贡献保持、增量归属相符。旧库其余分片没有被本轮计入训练。这里只能验证被观察和审计的目标，CE 对全域归一化仍可能压低未知的有效计算。[数据来源、分折和核验计数](training.json)
- **对照**。三个 EggCC 程序逐一留出，训练种子 71、113，各组来自同一 both-71 检查点。small 仅使用旧原生分叉。expanded 混合分叉、Teacher、自主和基础 Higher 状态。feedback 使用与 expanded 完全相同的状态、目标、曝光和初值，加入未来角色读取。replay 在同预算中引入 32 个纯自主程序及遗漏。四组每折各有 512 次更新、512 枚完整 Token 曝光；日志中的 states、targets 是实际抽到的来源记录和目标，不等于全部可用监督。sweep 在相同既有网络上按规范化状态归并多目标，每折遍历全部具名目标两次，单状态内平均普通完整 CE。共享前缀只缓存相同条件概率的计算。每折有 622–640 个状态、16,350–17,017 个不同的「状态 × 具名 Token」，曝光为其两倍。等效物理引用可能共享贡献，这一数量不能解释成独立新增事实数。sweep 同时增加了曝光和优化步骤，和 512 曝光的差异不能仅归因于数据规模。

## 重复与执行语义

完整身份包含所选模板及每个父的 `(owner, op, version)`。重复计数先判同页，再判跨 Submit；跨 Run 与新版本另计。原生 `admit` 在检查通过后按规则及实际输入值识别已签名实例。相同具名 Token 仍可能收到 untriggered、binding 或 watermark；这些回执各自保留。两个不同模板也可能指向相同 Primitive 入口。记录 `native_duplicate_new_refs` 表示此种原生 duplicate 的具名入口尚无先前外部接受记录，内部签发和跨模板情况也需考虑。[原生准入](../../../../../../engine/cell-runtime/src/cell_tokens.rs)

对 17 对不同物理引用，离线执行空分支、仅原请求、仅替代、先原后替代。17 对均满足两个单独分支新增操作数相同且大于零，当前 Run 的完整导出图相同，联合分支第二枚被原生识别为重复且贡献为零。样本按候选字段相同选取，每窗口最多一对，只能说明这种别名确实存在。这项筛选仅在离线分叉中使用。[四分支核验](aliases.json)

正式执行使用同一单线程策略、CCP v0.1 Rust Runtime、固定退出、每 Run 六个槽分两次 Submit。生成种子 193、307 同时影响抽样和原生物理地址。静态类型决定可构造域；训练目标、有效操作台账、别名搜索和未来回执均不进入在线解码。Response 只提供上下文，不能作为已发布的父引用。页内不放回只扣除已生成的完整具名叶子，每次 Submit 重新开始。原 KV、因子化随机和历史稀疏保留各自的 IID 路径，并另测原 KV 不放回。稀疏对照沿用既有内部 posting RNG。正确 Recipe、正确首父和原生分叉属于离线诊断。[逐次预算、计时和终图](native.csv) · [实际事实集合](facts.json)

## 回执与结构泛化

训练种子 71、生成种子 193 的两组交替计时均复现各自的事实集合、终图、付费请求和有效操作。即使两组在 loopfact 都发现 95 项，也只有 80 项相同，各自独有 15 项。两次正反序墙钟均值（expanded / sweep）为 fact 20.09 / 19.97 秒、loopfact 16.65 / 18.00 秒、sum-divisors 18.04 / 20.87 秒。三个程序均无同终图加速结论。[全部原生计时](native.csv)

**Response 与抽样**。以 expanded、训练种子 71、生成种子 193 对齐三个程序的完整调度。IID 共签发 4,356 枚，269 枚为同页具名重复，2,251 枚为跨 Submit 重签，产生 480 个有效操作。页内不放回组签发 4,598 枚，同页重复为零，跨 Submit 仍有 2,517 枚，产生 546 个有效操作，4,010 个请求收到 untriggered_rule。关闭 Response 输入、保留不放回时，跨 Submit 重签为 2,687/4,752，得到 519 个有效操作。这些自主轨迹会分岔。另在相同自主状态上只切换 Response KV，36 个当时有贡献的目标平均 log 概率差为 +0.008；可再次构造的历史 accepted 和 duplicate 样本只有 2 和 6 个，打开 Response 后八枚的概率都升高。Response 会改变决策，尚未显示可靠的执行后去重规律。本轮完整自主轨迹未观察到完全相同的版本化 Token 在另一 Run 重新获得新增贡献，不能据此永久排除它。[同状态回执消融](response-probe.jsonl)

**结构泛化**。按结构化 Bake 签名区分本轮全量训练实际曝光的规则。留出 Teacher 的 2,690 个目标中，46 个来自未曝光签名；纯自主的 36 个目标中有 5 个。测试按来源、程序和签名是否见过分层，每层最多随机抽 48 个。父数与难度在不同层的分布不同。12 次全量训练模型的 EggCC 完整自主运行中，已见规则 Primitive 有 11,807 次签发、385 次新增贡献；本轮未见规则 Primitive 有 6,380 次签发、45 次新增贡献；Higher 有 849 次签发、零新增贡献。共享初始权重的更早训练史未按本轮签名隔离。[逐目标泛化](generalization.jsonl) · [自主签发按规则拆分](generalization-free.csv)

所有权重冻结后，重新编译两种入口父数的原生混合环境，使用新输入、四条分支、九步 Higher 和改变后的末段算术操作。新 Higher 的规范化签名均与训练目录分离。从完整 Memory 自主生成，两个训练种子、两个生成种子、两种入口合计八次运行。small、expanded、replay、sweep 的自主选择与有贡献的完整执行次数依次为 21/6、38/16、30/10、36/9。本项使用 fact 留出折权重。受控环境证明了主动实例化新结构的能力；EggCC 的 Higher 仍缺少可归因的有效压缩。[冻结后新 Bake 原生结果](new-higher.csv)
