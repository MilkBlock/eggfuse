# 目标、有效计算身份与对照

本轮属于 Neural Execution。因子化随机作为无学习控制，使用与神经方法相同的物理构造域。实验使用真实 EggCC Cell Runtime、CCP v0.1、原 Query 环境和 Metal 物理地址树。网络对所有同类对照使用相同的 GNN、Actor、复制门、owner 投影和直接模板生成器。训练仅更新现有地址 MLP。宿主在线只提供既有调度、物理类型、可见端口及版本信息。原生核验发生在签发之后。训练使用的别名集合、有效结果签名、原生拒绝标签及精确分叉均不进入线上生成器。

## 有效集合

监督复用原有 108 个训练状态，包括 sum、dot、训练 grammar 的 teacher 轨迹及两份独立 Cell Stream 轨迹。4,557 个见证组中，2,349 个具有原生归属的有效贡献。一次成功的完整绑定及其经原生核验的可替代地址共享一个签名。Higher 与对应 Primitive 签发同一根请求时，该见证只记一次。冻结评估只核算已核验的根贡献。独立执行中只有实际执行的内部步骤才能按原生账本取得有效操作收益。当前实验没有为未实例化的任意 Higher 后缀估算奖励。

未见证绑定保留 Unknown，合法但缺乏即时归属的计算保留原标签。Coverage 优化已知有效签名集合的发现数，该集合给出可测下界。每个状态单独计数。可以用同一个 Token 到达多个原子效果，冻结指标的单位始终是不同计算签名；独立执行的 EPT、EPS 使用原有有效原子操作数。

从冻结 D 在训练程序上的真实独立轨迹回收负监督，保留生成现场并在原生回执后关联具体请求。只对确证的 dirty=false 未触发拒绝惩罚该上下文的模板质量，对 binding 拒绝惩罚给定相应模板后的具体完整绑定质量。重复、guard、pending 和当步没有新事实都不参与负监督。按原生 Run 编号模 8 取样，并保留观测到的 575 绑定失败。每两个更新分别抽模板拒绝与绑定拒绝，四个更新中有一次从含 575 失败的绑定页取样。所有评估程序与训练程序隔离。

## 固定完整 Token 预算的梯度

设一次物理地址树尝试抽出完整 Token 的概率为 Z，完整 Token i 的非条件概率为 p_i，重复尝试后交付的每一枚完整 Token 服从 q_i=p_i/Z。目标是 B 次独立完整抽样的期望不同签名数。对每个见证签名 g，所有已认证地址的 q_i 求和得 q_g，贡献为 1−(1−q_g)^B。对已经多次命中的签名，继续增加其质量的边际收益下降。

正式训练直接从当前神经生成器抽取两页独立、各 B 枚的完整 Token。对每一枚 x_i，h_i 在其有效签名只在本页出现一次时为 1，否则为 0。每个位置对期望不同签名数梯度的贡献为 E[h_i ∇log q(x_i)]，因为删除该位置仍可得到的签名数与 x_i 独立。使用另一页的同位置样本 y_i 后可写成 E[h_i (∇log p(x_i) − ∇log p(y_i))]。原因是完整样本上的 E[∇log p(y)] 等于 ∇log Z。利用两页互换后的平均作为训练估计。这样既对等价地址共享发现信用，也直接校正了构造失败后的重复抽样。对唯一物理路径的梯度稀疏抽样时使用逆抽样概率加权，小域穷举测试检查梯度与公式的解析导数一致。

训练预算 B 在 4、16、64、256 之间均匀抽取。每个训练种子使用相同的初始化权重、快照顺序、AdamW、学习率 0.00015、梯度裁剪和 768 次更新。原 Loss 对一个状态中的见证签名等权，对每个签名使用原始的已验证等价地址对数似然。它在这里重训为配平的对照，和上一轮按签名数量抽取状态的历史 D 有不同的快照权重。失败监督组在相同 Coverage 目标上加入上述实际拒绝项。冻结 MLP 之外的参数，所有组复用同一原生执行机制。

## 试验性归一化的误差

另做了离线解析公式的试验。5 个物理域至多 512 枚的状态精确计算 Z，其余 103 个使用确定性混合重要性抽样，枚举见证部分并抽样其余部分。训练后在未用于估计的 Metal 槽位上重新测量了 Z。在抽查的 20 个近似归一化训练状态上，Coverage 组的平均绝对误差达 8.68，个别估计超过 1；5 个精确状态的平均绝对误差为 0.008。该估计器无法可靠跟随训练后的策略。正式神经成绩采用上面的当前策略梯度。[校准逐状态数据](calibration.csv)

## 评估口径

冻结比较复用同一批 109 个 Teacher 状态及从历史 D 独立执行抽出的 76 个自主状态。各训练种子分别抽五个生成种子。前沿上每个状态的完整预算为 B 与物理域容量的较小值，与上一轮一致。抽到无法形成完整 Token 的槽位继续尝试；记录尝试上限、实际交付数和各组配平后的完整前缀。核验同一计算的重复地址在统计时复原原始抽样顺序。原生参考外的合法结果不记为无效。表内发现数先按状态求和再取种子均值，自主状态按原有产出分层，未按在线访问频率加权。

独立执行每 Run 两页，每页最多 16 枚完整 Token，沿用上一轮每页最多 1,024 个尝试的线上边界。记录完整页欠额、原生拒绝、实际付费数及所有有效操作。冻结实验的额外抽样预算不用于独立执行。三对训练种子和独立生成种子分别为 (9633,536)、(5003,1129)、(1777,3449)。Coverage 和 EPT 取三对均值。端到端 EPS 使用 (9633,536) 单独正反序运行的中位数，包含模型装载、Metal 寻址、构造失败、通信与原生执行。各组的终图哈希另存。终图不同的 EPS 仅表示各自实际有效操作吞吐。
