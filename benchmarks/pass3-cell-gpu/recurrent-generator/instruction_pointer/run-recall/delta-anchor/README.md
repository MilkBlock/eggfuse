# Where the EggCC pointer loses bindings

The original width-32 pointer reproduces the distinct accepted teacher count on every Run of the three EggCC programs. Every signed full request in the shadow interventions was passed to the search-free native receiver. Its credit is a distinct reference binding at that Run, including an alternative accepted proof. A commit may change a function or union two existing classes. This denominator does not measure final graph nodes.

The first three columns of interventions run on sealed teacher snapshots. The last is selected-side attribution in a live, semantically checked hybrid. Two zero-table obligations per program use the ordinary native path and receive no anchor credit. The supplied-anchor control substitutes all recorded first-fresh anchors, without an anchor cap. It retains the downstream beam, and can drop useful alternative anchors. It is a conditional experiment, not a bound on every conceivable pointer. The Δ-order test keeps weights and thresholds frozen; training for this order could give a different result.

The native census enumerates physical witnesses per scheduled rule and pivot. Each witness is actually expanded with argument checks, typed point steps and general exact completion as needed. Membership uses the rule watermark and the sealed source epoch; the first fresh atom owns the proof. A separate ordinary native match checks the input-key set on each triggered table rule. The full schedule, RHS, writes, resumes, events and final digest match the capture. Native ns exclude discovery, row sorting and post-expansion accounting. Neural ns are amortized batched root scoring alone in one CPU thread. Encoding, selection and multiple logical aliases of a physical row matter in a full execution. The recorded alias-score and physical-anchor timings are separate timed traversals on the same machine.

| sum-divisors | 112,461 | 17,515 / 26,587 | 37,614 / 102,596 | 22,685 |

After validating each named anchor and resolving its actual witness, the runtime partitions each physical domain. It fully expands the selected partition once, and applies the exact fallback to the complement. It preserves normal ordering, graph effects and existing continuations. Counts in both partitions sum to the empty-selector control for both measured operation types. Candidate visits count successful generic row candidates; baked point reads include misses. An untouched exact reference uses the original matcher and can visit fewer candidates than the experimental anchor enumerator. Unselected anchors require fallback for exact saturation. Hybrid coverage includes native parent search and is ineligible for search-free model or signed-token credit.

These costs characterize this CPU/Python implementation; they are unsuitable for a GPU speed claim.

## Artifacts and reproduction

The [summary](summary.json) includes per-arm duplicates, rejection causes, scoring counts, complete nonempty Runs, the additional recovery-head control, binary and weight hashes, and native exact/replay samples. [Per-rule and pivot census](anchors.csv.gz), [first missing canonical prefix per missed commit](missing.csv.gz), and [per-Run recall](recall.csv.gz) are gzip-compressed CSVs. Runs with no teacher submission remain visible in the ledger and have no recall denominator. The [matched binary full-tuple ablation](../sibling-issue/README.md) tests whether delaying the first irreversible prune helps at equal paid requests.

Use the capture, memory and program files from the parent-credit experiment, its calibrated opaque Actor and the native-prefix-recovery head. Build cell_token_replay with the cell-token-ept feature in release mode. For each program folder, run the following commands with the paths to those inputs. Replace U with the existing ordinary search-free receiver, B with the native binary from this study, D with the program folder, M with the Actor file, H with the recovery directory and O with an output stem.

```sh
B anchor-census D/program.json - audit > O-final-census.json
python anchor_scoring_cost.py D M H O-scores.json
python anchor_controls.py D B O-controls.json
python anchor_partition.py D M H B O-historical-partition.json --historical --mode model
python anchor_partition.py D M H B O-final-empty.json --historical --mode empty
python anchor_partition.py D M H B O-model.json --mode model
for mode in source delta oracle-source; do
  python delta_pointer_ablation.py D M H U O-historical-$mode.json --historical --mode $mode
done
for mode in source delta oracle; do
  python delta_pointer_ablation.py D M H U O-$mode.json --mode $mode
done
python delta_anchor_report.py EXPERIMENT_ROOT RAW_OUTPUT_DIR REPORT_DIR fact loopfact sum-divisors
```
