# 同一计算窗口中的 Teacher 潜力与神经兑现

固定退出策略运行时，4,332 个动态 Run 入口中有 1,736 个拿到了原生核验的新增计算见证。其中 93 个入口的神经页兑现了零个有效原子操作。训练库同时保留这些窗口的正向具名绑定、策略实际签发的请求、原生回执和费用。部署沿用 CCP v0.1 和原固定退出策略。本次运行使用 Rust CCP Native Runtime 和 Metal 神经推理；上游 egglog 的性能未在本轮测量。

## 同状态分叉

每个冻结决策点保存程序、Stage、epoch、完整已签发前缀、神经上下文和合法动作掩码。重新装载时逐项检查前缀回执、已发布状态或控制输入。离线 Teacher 在同一发布状态枚举具名请求，把请求放回真实准入前缀上重放。新增有效操作由签发 ID 的原生 origin 确认；原请求的 credit 发生转移或新增总量对不上时，该项保留 Unknown。见证给出该试验实现的潜力下界。没有正见证时，饱和、计算无价值以及应当退出的监督均保持未知。

| 同状态比较 | 窗口 | 有正见证且可归因 | 其中策略兑现零个操作 |
|---|---:|---:|---:|
| 固定退出，新动态经验，当前页 | 4,332 | 1,736 | 93 |
| 冻结模型，排空草稿后的 Continue 第一页 | 344 | 120 | 22 |
| 新模型，训练留出程序，同起点同随机数 | 62 | 19 | 1 |
| 冻结模型，上行相同的 62 个起点 | 62 | 19 | 2 |

344 对中有 187 对复用已经测得的实时神经分叉，157 对为本轮新执行。22 个零兑现窗口中，20 个签发后没有新增操作，2 个没有可用的抽样尝试。分叉从有可比后续发布的退出点抽样，表中比例仅描述这些窗口。固定页首与排空后的退出点是不同的分布。

每个实时分叉把一页神经预算放在当前发布之前或之后，接下来的两页使用各自的真实 Response。比较三页后的参考事实集合，冻结模型下 47 对 Continue 严格占优、43 对 Seal 严格占优、36 对各有所得、218 对事实集合相同。继续一侧共实际付费 10,502 次，先发布一侧 10,299 次。分配的页预算相同，成功构造及签发的数量可以不同。三页预算内观察到的差异只给对应策略、预算与控制动作记账。首个 Seal 后页的收益属于下一窗口。62 个留出起点上，更新权重后有 6 个首个 Continue 页比原模型兑现更多，5 个更少，50 个相同，1 个归因未知；两次分别兑现 48 和 46 个有效操作。该差距不足以支持稳定的能力提升。[逐对成本](allocations.csv) · [含完整具名请求的实际案例](paired-example.json)

## 动态采集与训练

96 个动态 Recipe、192 条轨迹产生 **417,450** 枚新签发的神经 Cell Token。181,602 枚来自全程自主轨迹，235,848 枚由网络在包含合法 Shuffle 或探索辅助的训练轨迹上生成。额外注入的 Teacher 与随机请求单列。4,236 个不同决策状态产生 80,373 个可从单输出 Recipe 结构和原生结果确认的不同“状态 × 有效计算”下界。历史和新增档按相同状态标识合并后共 17,885 个不同状态、325,839 个单输出有效计算标签下界。全程自主轨迹累计 **1,403,990** 枚，混合轨迹另有 481,522 枚神经签发。该训练家族使用 Primitive，多数状态来自生成的多 Stage 程序。

本轮另得 69,247 条原生遗漏记录、768 个经核验的局部替换、703 条经核验的后继依赖。观察到 233,881 次未触发回执，其未核验的父绑定维度保持 Unknown。统一经验读取器对齐了 4,332 次 Continue、5,655 次实际 Submit、4,332 次固定 Seal。固定退出作为观察动作保存，动作优劣需要独立分叉证据。页首 Teacher 见证、签发后的剩余遗漏和 Seal 后的事实差集分别带有自己的时间范围。417,450 枚 Token 的采集用时 177.7 秒，包含在线执行和采集器内置的遗漏审计，约 2,349 枚/秒；额外离线审计另行运行。[数据与 Credit 清单](experience.json) · [固定页经验接口](../../dual_credit_pages.py) · [实时控制经验接口](../../control_credit_experience.py)

只训练原有计算地址参数。64 个训练程序、两个训练种子，每种监督每个种子 512 次更新。两组共享状态、初始权重、局部替换及同 Token 跨状态对照。D 的发现损失使用策略已经兑现的计算，witness 组还把具名遗漏正例加入同一发现损失。预页 Teacher 重放用于独立测量，训练使用现有原生剩余遗漏见证。侧重生成质量，控制权重沿用原值。离线 Teacher、替代绑定、后继结果和控制偏好不进入在线 Query。Runtime 在线处理指定请求并返回真实结果。[权重校验和](weights.csv)

## 固定退出的独立执行

每格依次为 Coverage（%）、EPT、端到端 EPS。两个训练及生成种子等权；首个种子正反序测量，验相同终图和付费数后折叠计时。共 48 次完整执行。EPS 包含冷启动及设备推理。正序计时的一部分与离线 CPU 数据审计重叠，原始耗时范围一并保留。相同预算的各组终图不同，此表不能推导同终图加速比。

| 工作负载 | 因子化随机 | 冻结初始策略 | 实际兑现监督 D | 增加遗漏正例 |
|---|---|---|---|---|
| fact | 10.71 / .0238 / 127.7 | 9.87 / .0243 / 28.6 | 6.52 / .0192 / 5.8 | 7.32 / .0210 / 6.7 |
| loopfact | 11.02 / .0220 / 108.5 | 10.84 / .0217 / 26.0 | 8.86 / .0171 / 6.3 | 7.96 / .0165 / 5.7 |
| sum-divisors | 2.68 / .0462 / 225.1 | 2.42 / .0386 / 49.6 | 2.11 / .0408 / 11.4 | 2.13 / .0421 / 12.4 |
| 留出 grammar | 12.02 / .4375 / 476.8 | 9.23 / .3359 / 210.0 | 6.44 / .2344 / 113.7 | 7.73 / .2812 / 141.9 |

训练后，构造完整 Token 所需的重复采样明显增加。fact 的第一个种子中，初始策略用了 23,424 次神经槽尝试并付费 7,475 次；增加遗漏正例后用了 215,600 次尝试，只付费 6,282 次，仍有 1,172 个完整 Token 的预算缺口。固定退出下也能复现损失。一次监督消融尚不能把下降唯一归因于数据分布、抽样目标或绑定能力。[完整指标](metrics.csv) · [每次运行](runs.csv) · [事实集合](facts.json) · [历史高召回 Cell Stream 及预算差异](../neural-execution-control/README.md)

三个 EggCC 程序各抽取 10 个自主到达的窗口，按是否收到接受回执分层。离线每个窗口最多试 128 个具名 Teacher 绑定，先验真实独立执行的终图哈希，再核对窗口准入数量和 origin。loopfact 的 Run 5、93 都有 1 个可核验操作，策略当窗兑现为零；sum-divisors 的 Run 5 和 18 分别为 1 和 6，策略均为零。fact 的十个样本没有观察到这种落差。该检查属于事后诊断，已接受的请求和全体签发计数分别保留，样本不估计整条任务的漏推率。

## 复现

从 instruction_pointer 目录运行脚本。BASE 指向移动盘 eggfuse-experiments，DATA 指向原生工作负载，RUNTIME 指向 cell_token_replay，OUT 使用新的输出目录，PY 指向可用的 PyTorch Metal Python。原始 buffer、逐请求 Credit、page-dual、实时分叉、更新权重后的分叉、原生独立执行终图及权重保存在移动盘 discovery-dual-credit。归档读取器会核对权重、程序、付费前缀或源分片摘要。sum-bits README 的编译、执行和五次 bench 均已跑通，已有 sum-bits 语义契约验收通过。[复现脚本](reproduce.sh)
