# 原生执行环境与等价地址监督

在相同的 109 个冻结状态上，D 在每状态 256 次生成尝试中命中了 220 个有原生贡献的不同签名绑定，A 命中 193 个。四个程序改为独立运行后，D 签发 9,958 个付费请求，得到 485 个署名有效原子操作；A 用 8,987 个得到 486 个。此次正收益局限于给定快照的累计召回。实验基于 `05ba8636` 的实际 Rust Cell Runtime 和 Metal 地址生成路径。

## 真实 Query 和寻址边界

1. 原生调度器构造当前 ruleset 的完整有序规则表，读取该规则实际生效的 watermark，再将原有 dirty 数组、是否启用 dirty 检查、epoch 交给 `CellHistory::observe`。可选只读观察文件在同一个 publication 写出每条已调度规则的原始状态。B/D 按发布顺序读一行，核对 Run、epoch、规则顺序和水位。训练重放与独立执行各自产生自己的观察文件。CCP v0.1 字节布局、签发和执行路径沿用原实现。[原生观察器](../../../../../../engine/cell-runtime/src/cell_tokens.rs)
2. B/D 在原有 32 维表示中加入当前规则的 dirty 位、watermark 和 dirty 检查开关。选模板时这些量加在两个实际读取的 pivot Key 上，选定模板后进入父地址 Query。公共 Query 读取 epoch、Run、这次发布和退役的端口数、收到的签名数及最近发布端口的版本。端口 Key 仍由原有编码器读取该行的实际版本、转发状态和字段表示。标量映射与坐标固定，训练参数数量相同。每次发布为当前调度表更新模板特征的 CPU 工作、磁盘侧通道和 GPU 上传均进入独立运行墙钟。该侧通道属于实验观察器。[Query 和 Metal 更新](../../query_environment.py) · [端口编码](../../latent_cell_flow.py)
3. A/C 与 B/D 使用相同的物理树、模板词表、按静态类型建立的父端口域、复制门和已选 owner 的具名投影。CPU 发布 dirty 为 false 的规则，也保留其物理叶子和原始位置。原生核验在网络签发后依次判断未触发、绑定、guard、水位等条件，合法绑定按规则及已绑定输入值检查重复。程序遇到的首个实际拒绝原因单列，未触发的请求没有后续父绑定标签。训练只使用已核验的正例。四组沿用旧模型对批内前一次回复的接受/未接受反馈；没有把各类拒绝混成训练负例。在线没有用等价表、跨角色水位比较或任何 can_skip 掩码。[原生签发核验](../../../../../../engine/cell-runtime/src/token_transaction.rs) · [共享 Metal 采样器](../../draft_page.metal)

## 数据和目标

主实验沿用 sum、dot、fork grammar 的 teacher 和独立 rollout 共 108 个训练状态、4,557 个签名绑定。每个上下文尝试单父替换，原生离线重放整枚 Token，要求命中原来同一个签名绑定。训练端额外核验出 4,140 种替代。fact、loopfact、sum-divisors 和留出 grammar 的 109 个状态、6,423 个原始绑定及前轮 5,148 个替代全部用于留出测量。累计召回也承认抽样中出现的其他原生同签名证明。每份独立目录隔离训练、评估程序和 rollout 来源；这些 EggCC 程序是项目历史开发用例。[样本清单](witnesses.json) · [双执行器重放核对](witness-check.json)

对每个不同的已签名计算分别计损失。A/B 优化原始完整地址的负对数概率；C/D 优化原始地址与已核验替代的联合概率之和的负对数。每个绑定独立占一个目标位置，拥有更多同义地址不会增加它的抽样权重。路径概率包含模板、前缀条件化父地址、复制门及 owner 投影的条件后验。没有组合未经核验的多槽替换。单槽换址核验仅给出等价类的已知子集。训练同时保留合法但无署名有效操作的目标，召回表另列确有贡献的子集。[组损失](../../query_fit.py) · [离线证书](../../query_witnesses.py)

四组从同一历史 checkpoint 初始化，冻结 GNN、Actor 和原复制门，更新既有 314,369 参数的地址比较器。每组 768 次 AdamW 更新，每次同样的 32 个签名目标，使用相同抽样种子、学习率和正例集合。A 是按这套预算重训的当前 Query 加物理地址监督。历史冻结树与高召回 Cell Stream 保留为不同预算/机制的历史对照。[历史地址树结果](../address-audit/README.md)

另做三个程序留一的 A/C 敏感性实验。每次只将其他两个 EggCC 程序的已核验替代加入训练；因此前一轮 5,148 次替代都实际进入过训练，也都在没有该程序的折中被评估。留出 fact、loopfact、sum-divisors 的等价类概率分别从 0.02221%、0.07082%、0.03769% 到 0.02227%、0.07530%、0.03799%。这组补充实验测量冻结快照上的跨程序地址概率。[各折与主实验](probabilities.csv)

## 独立执行

每 Run 两页、每页 16 次生成尝试，同一抽样种子。四程序 × 四组 × 正反两种执行顺序共 32 次，均运行至原生调度结束；每对重复运行的终图哈希、事实集合、付费请求及回执计数一致。EPS 包含冷启动、环境观察、CPU/Metal 寻址、通信、执行和状态更新，表中取配对中位数。EPT 是署名有效原子操作除以所有付费请求。每个表格单元依次给出覆盖的参考事实数、EPT 和 EPS。

| 工作负载及参考事实数 | A | B | C | D |
|---|---|---|---|---|
| fact / 1,120 | 68 · .0501 · 45.0 | 59 · .0434 · 45.2 | 65 · .0399 · 44.3 | 55 · .0390 · 43.5 |
| loopfact / 1,112 | 79 · .0329 · 40.6 | 83 · .0316 · 38.6 | 70 · .0414 · 36.1 | 77 · .0380 · 38.3 |
| sum-divisors / 8,018 | 149 · .0779 · 87.3 | 155 · .0611 · 75.0 | 152 · .0688 · 79.5 | 154 · .0616 · 74.5 |
| 留出 grammar / 233 | 0 · 0 · 0 | 0 · 0 · 0 | 0 · 0 · 0 | 3 · .0714 · 34.0 |

sum-divisors 上 D 找到了 A 遗漏的 25 个事实，也遗漏了 A 找到的 20 个。未触发请求从 2,971 增至 3,914，付费请求从 3,339 增至 4,315，有效原子操作从 260 增至 266。对全部四个 workload 汇总一遍，A/B/C/D 的未触发请求为 7,973 / 9,184 / 7,994 / 8,842。独立执行会改变后续证据、调度轮数和下一页查询。这里没有足够证据将冻结快照上的未触发减少解释为端到端加速。原高召回 Cell Stream 在 sum-divisors 的历史覆盖为 3,137/8,018，当前所有组仍在低覆盖区间。[原生逐组终图、事实差异和分类回执](native.csv) · [各方向计时与访问量](costs.csv)

## 复现与限制

运行 [复现脚本](reproduce.sh)。本次使用单训练种子和单生成种子；两次计时重复不能估计训练随机性。程序留一补充实验仍限于这几种计算分布。相同预算的各组得到不同终图，当前数据不能给出同终图加速比。

原始签发和回执、逐目标准确概率、每次独立执行的终图与事实集合、训练损失和权重存于移动盘的 `eggfuse-experiments/query-contract-1126`。训练后逐目标文件位于 `prob-{A,B,C,D}.csv.gz`。仓库保留可复现源代码、分组结果和权重校验摘要。已有 sum-bits 语义验收用保存的原生导出重跑通过。CPU 编译、运行及 benchmark 烟测通过，140 项 Python 测试通过。[权重校验](weights.json) · [语义验收](semantic.json)
