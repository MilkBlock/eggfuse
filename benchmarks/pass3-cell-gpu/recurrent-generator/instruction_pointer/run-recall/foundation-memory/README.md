# 共享关联 Memory 与证据先行的完整 Cell Completion

在固定退出、CCP v0.1 的三个真实 EggCC 程序中，完成了共享发布索引和可变顺序的完整 Token 生成。实验证实，神经索引可以在目录追加入口时复用所有已编码行。独立运行尚未证实模型会主动利用证据入口完成有效计算。主种子 271 次自主证据起步只得到 8 个付费请求，原生新增贡献为零。

## 执行边界与数据表示

一条发布记录是具名的 (owner, op, version)。索引接口只接收发布/退役及行表示。沿用原 Cell Encoder 的整体端口向量，逐字段取公开 64 位值指纹的位特征，复用冻结的四头坐标及权重形成每字段 88 维表示。物理页按静态表类型和发布位置组织，每页至多 32 行，存储独立字段向量、同行身份、整体向量和页均值。更新替换旧版本，退役移除行；仅受影响的页重新打包。行张量与页张量两份物理存储均计入报告。宿主另有版本/地址映射和物理页目录，张量字节未包含 Python 元数据、临时计算图和分配器预留。在长期退役压力下，物理页目录的历史条目数仍可能增长。[共享索引实现](../../foundation_memory.py)

解码器先给物理页的整体表示打分，再读取一个页。在已绑定父角色的条件下，对页中每个候选行，按 Bake 给定的静态字段接线累加该行的字段相似度，加上原地址 MLP 的分数。一个候选的各项分数来自同一具名行。没有为字段子集预建 posting，没有枚举不同角色行之间的笛卡尔积。页均值没有完备的伙伴存在性信息，目标可能在选页时丢失。此原型是用神经打分的两层物理页索引。其页级读出仍扫描可选页，未实现目录和 Memory 同时增长时的常数成本定位。端口聚合的物理归属与 Recipe 无关。[生成与按行打分](../../foundation_completion.py)

每个模板保留静态描述、接口及角色接线。Recipe 入口对当前调度集合打分。证据入口在「从 Recipe 开始」与所有可见物理页之间做神经选择，再自主选行，随后在其静态类型能填充的 (Recipe, role) 中选择；找不到静态角色时该尝试失败。模型读取公开的发布、事件、规则 dirty、水位和类型域规模。宿主未在选择证据前按可命中规则、值、freshness、guard 或 teacher 信息剔除行。选择角色后解码所有剩余引用，并恢复原语义角色顺序再签发。零父请求通过 Recipe 入口完成。此次开放 EggCC 对照生成 Primitive；Higher 在控制外部接口的独立原生实验中复用相同的父引用补全函数。未测开放 EggCC 上的自主 Higher 激活或任意 Transaction 局部依赖生成。

## 训练

复用前轮已原生核验的 Teacher 与自主状态，保留 614 个不同的来源×Run×完整具名 Token，覆盖 176 个来源×Run。12 个动态程序提供 480 个目标，三个 EggCC Teacher 提供 98 个，自主状态提供 36 个。零、一、二、三、五、六父目标分别为 7、223、212、164、7、1 个。按 EggCC 程序留出，同时排除其自主轨迹；不同 EggCC 程序可以共享编译规则。每折用同一初始化、同一训练样本、同一批次序列和原有 gate/scorer，两种分解均进行 240 次 Adam 更新、960 次完整目标曝光。前 40 步取训练集较小的 20% 上下文，至 100 步取较小的 60%，随后纳入所有规模。[完整语料清单](corpus.csv) · [Metal CE 实现](../../foundation_study.py)

Rule-first 直接计算模板及所有父引用的条件概率乘积。混合入口计算完整 Token 的概率，等于 Recipe 路径概率加上该 Token 各父角色作为首个证据的路径概率之和。对该总概率取负对数；训练时才展开一个已知目标的这些路径。上线每槽只抽一条路径。没有额外预测头、RL 奖励、门槛分类或正确起始角色标签。小域归一化测试覆盖零父和重复父引用。三个程序的混合模型留出 CE 都下降，但终点都高于同预算 Rule-first。单训练种子，不能据此判断大规模预训练上限。[训练曲线](training.csv)

- **固定权重的寻址算法。** 上轮权重从原联合 posting/回退解码换到共享物理页和同行打分，三项参考事实数从 94/85/152 降为 69/69/131。两种实现从相同种子开始但消耗随机数的顺序不同。这是整个寻址算法的消融，不能单独归因于页均值或字段投影。
- **固定索引后的学习。** 相较于训练前的初始化，本轮 CE 把共享页 Rule-first 的 51/59/119 项变为 62/76/113 项，混合入口从 49/51/111 项变为 66/64/151 项。保持本轮 Rule-first 权重、只关闭同行字段项，三项变为 58/72/111。固定字段投影提供了独立于这轮梯度更新的关系偏置。
- **生成顺序与资源。** 主种子两组各限制到恰好 1,904 次尝试时，仍分别为 62/76/113 和 66/64/151。按 541/745/742 总付费上限，两组仍得到这些数目，sum-divisors 的 Rule-first 只用了 603 枚。训练后用相同混合权重强制从 Recipe 开始，得到 53/72/122。改变起步分布也改变后续抽样、发布与状态轨迹；这些整图差异不能直接记在证据入口上。
- **种子与事实集合。** 主种子及另外两个真实地址置换下，混合入口相对共享页 Rule-first 的事实数差按顺序为 fact +4/-2/-1，loopfact −12/−13/−16，sum-divisors +38/+13/−8。主种子两组交集分别为 48、55、107 项。没有建立同终图提速或稳定改善三指标的前沿。

## 自主选证据与给定证据

主种子的独立执行用原生 UID 做逐槽归因，审计运行复现无审计运行的终图。全程有 263 个已选证据在当前调度集合中没有同静态类型的输入角色。其余八枚请求分别为五次未触发、一次完整绑定失败、一次 guard 失败和一次原生重复。这个失败发生在不同的生成阶段，并不表明 263 个端口具有固定的负价值。[逐槽证据与回执](slots.csv) · [按入口分开的付费及有效操作](routes.csv)

**给定证据干预。** 从前轮冻结策略真实自主状态分叉，取存在已核验有贡献的非零父目标的 27 个检查点。每点八槽。提示组只给一个目标中的具名引用；目标 Rule、它占哪个角色、其余父引用都由网络选，原生重放核验。同一状态的自主对照仍可选择 Recipe。共 216 次尝试，提示组付费 195 枚，27 枚有新增贡献，共 63 个有效原子操作；自主对照付费 111 枚，32 枚有新增贡献，共 81 个操作。提示能帮助形成请求，但不能保证后续选择优于自由生成。各分叉相互独立，没有加进正式 Coverage。[配对提示诊断](hints.csv)

**信用分配的证据。** 对留出集中非零父的已核验 Token，计算在已经生成该目标的条件下，各构造路径的后验概率。训练前经证据入口的后验中位数在 fact/loopfact/sum-divisors 为 17.45%/29.18%/32.38%；训练后为 0.00455%/0.0391%/0.240%。CE 允许经任意顺序实现同一目标。此训练预算下模型主要提高了从 Recipe 实现目标的概率。这个诊断与原生逐槽归因独立。[逐目标后验](posterior.csv)

## 扩展成本

独立的 Metal 成本夹具固定 32 行/物理页。已有 Memory 和类型下先注册一个 Recipe，再追加其他描述。256 行、每行四个字段时，1/16/64/256 个 Recipe 的索引张量均为 **787,456 字节**，追加目录引起的字段/行重新编码均为零。三次八槽生成的打分选项中位数从 694 增至 3,504；目录注册和角色表示也有成本。页耗时三次中位数为 46.5/45.8/52.0/41.6 ms，短程分派和同步占比较大，不能由这个时间序列推断目录增大带来加速。角色菜单仍需评分，且宿主仍要读取公开引用和静态角色表。测试固定已有类型和 Encoder 权重，没有在运行中的 Rust 程序热修改 Recipe 语义。

四字段、16 个 Recipe，在 32/256/1,024 行下索引为 98,432/787,456/3,149,824 字节。256 行、16 个 Recipe，在 1/4/8/16 个字段下分别为 246,784/787,456/1,508,352/2,950,144 字节。页内神经分数使用同行数据，不预建字段子集索引。在线实现逐槽、逐分类读回选择，`categorical_reads` 记录这些读回次数；当前端到端速度受此实现限制。可选位置打分和一次性目录/维护成本见[原始规模测量](scale.csv)。

**固定 Higher 外部契约。** 原生分叉/汇合程序固定两个外部引用和一个共享字段，八个独立任务，32 个入口槽。将实际 Higher GNN 结构编码供给入口寻址，已知模板，内部仅用真实具名回执和发布接续，逐步付费。6/32/128/256 个内部节点的外部索引均为 **38,144 字节**，三次运行中每档均完成 8/8，终图和独立原生参考一致。结构编码中位数从 0.63 增至 24.07 ms；32 槽寻址中位数为 78.2/77.6/75.7/75.5 ms。入口准备（含完整静态程序登记）从 3.6 增至 59.6 ms；原生实付请求从 72 增至 2,072，有效原子操作从 48 增至 2,048。保持入口索引大小仍需承担注册和内部执行成本。[实际原生耗时和终图核验](higher.csv)

## 复现

从 instruction_pointer 目录使用上一轮实际语料、已编译程序、初始权重和原生二进制。保留历史基线；正式独立执行没有给定证据、正确模板、跨角色水位筛选、CPU 字段 Join 或 teacher 补全。全部原生分叉均在独立的诊断脚本中。六份实际训练权重在实验盘，核对 [SHA-256](weights.json)。

```sh

export CELL_DATA=/tmp/dfm-local/data
export CELL_REPLAY=/tmp/cost-audit-build/release/examples/cell_token_replay

export PYTHON=/tmp/egg-txn-ml/bin/python
sh foundation_reproduce.sh
"$PYTHON" -m unittest test_foundation_memory test_multirule_discovery test_head_joint_index test_partner_index
```

仓库 sum-bits 已执行 Cargo compile、run、bench，原有 choice-diagnosis 语义合同返回 pass。新增回归检验完整 Token 概率质量、目录追加时的字段张量复用、版本退休及同行联合对照。开放工作负载的计时来自 CCP 原生 Cell Runtime；规模夹具只测神经索引与生成，不代表 EggCC 应用吞吐。
