# 变长 Cell 集合与真实 EggCC 父绑定

保留固定容量生产基线。复用已有结束读出，可以在一次机会内签发零枚、一枚或多枚完整 Cell。它在两个权重种子上都学会了受控 Wake 环境的边界，却在 fact 首次合法签发前就以很高的概率结束。独立的绑定对照显示，在给定正确活跃 Recipe 的二父任务中，历史关联寻址将原生 binding 拒绝从 247/368 降到 26/368。把当前 KV 改成全域扁平打分只降到 246/368。两个实验分开训练、计量和验收。

## 生成与监督

起点是研究分支 5af63c3e 的逐规则 dirty + watermark 模型。每枚 Cell 仍由模板、按其入口声明生成的全部具名引用组成。批次结束复用 InstructionActor 的 32→1 stop 线性读出。其输入为当前上下文加各原生入口族代表的评分向量按模型根概率加权的均值。令结束概率为 p，具体完整 Cell 的概率为 (1−p)P(Cell | 继续)。本轮只更新已有 33 个参数，保留原条件 Cell 分布。结束标签的 CE 是 −log p，完整 Cell 的 CE 是 −log(1−p)−log P(Cell | 继续)。同状态有多个已核验目标时均分条件 CE。每个权重种子 1,024 步，每步 64 个状态曝光。[训练与生成](../../variable_completion.py)

在 IID 模式下，本次 Submit 前状态固定，长度服从受容量截断的几何分布。当前读出不根据刚在同页抽到的具体 Cell 学习新的结束概率。在具名不放回模式中，已抽到的完整叶子只在本页移除。剩余条件质量为 R 时，下次结束概率为 p/[p+(1−p)R]。抽到结束就返回已有 Cell。零长度时原生 Submit 收到空列表，发送的计算请求为零。两次预定机会都空时，宿主仍按旧调度执行该 Run 本来就有的 Seal。每次空生成占用该机会的容量预算。原生调度可能随实际产出的事实走不同数量的 Run。[叶子抽样](../../competition_draw.py) · [原生调度](../../cell_kv_runtime.py)

监督来自小型真实 Wake、非对称 Wake 和混合 Primitive/Higher 原生分叉。继续需要见证有贡献的完整计算。结束要求在本解码器的可签发词汇中，存在静态可构造模板，且所有可构造入口在启用原生触发检查时均失活。Wake 样本同时核对所有枚举入口的原生 untriggered_rule 回执。Higher 从其实际签发的首条规则进入检查。后续内部接续由原有实例机制推进。当前自由生成器签发规则入口；若未来允许独立的 Computation Request，该证明须覆盖新增操作才能复用。域空、搜索不全、当前模型无产出均不能单独给出结束标签。在线只读取模型概率与原本公开的状态。[Rust 准入顺序](../../../../../../engine/cell-runtime/src/token_transaction.rs) · [原生分叉](../../foundation_wake.py)

每个种子训练 240 个继续状态和 120 个结束状态，留出 112 和 60 个。留出结束状态上的平均结束概率为 97.5% / 97.6%，留出继续状态为 1.7% / 1.8%。两者的实际差异在 EggCC 第一个窗口就出现。三个程序的唯一模板都是零父、活跃的 375，其条件模板概率均为 1。固定签发在 fact、loopfact、sum-divisors 分别归属 72、52、199 个有效原子操作。在任何签发之前，两种子对三个程序的结束概率分别是 96.5% / 82.7%、72.3% / 31.4%、8.1% / 1.2%。此处可排除父绑定错误。模型在未见程序中把入口判为应结束，当前实验无法单独归因到哪一个上下文特征。[学习曲线](training.json) · [逐窗口概率、dirty、请求 ID 与实际贡献](windows.json)

## 真实自由生成

保留完整 CCP v0.1、固定退出与既有 Higher 目录。每 Run 两次预定机会，每次最多 3 枚完整 Cell。固定槽组最多提供 384 槽，固定付费组最多 96 个实际协议请求，完整调度组运行至原生退出。每组两个训练权重种子，共用生成种子 193。表中是完整调度最终覆盖的不同参考事实个数，两个数依次对应种子 71、113。分母已扣除初始事实。

| 程序 | 参考事实 | 固定 IID | 变长 IID | 变长页内不放回 | 固定页内不放回 |
|---|---:|---:|---:|---:|---:|
| fact | 1,120 | 61 / 60 | 2 / 1 | 2 / 1 | 78 / 75 |
| loopfact | 1,112 | 78 / 84 | 2 / 76 | 2 / 76 | 81 / 80 |
| sum-divisors | 8,018 | 147 / 139 | 143 / 147 | 149 / 149 | 146 / 141 |

六次完整执行合计，固定 IID 生成 8,550 枚，变长 IID 生成 1,949 枚。后者有 2,880 次空生成，长度 1、2、3 的机会数分别是 196、83、529。包括空类型域造成的空页，另列实际抽到结束的次数。未触发请求从 7,724 降到 1,481，绑定拒绝从 476 降到 310，原生重复从 150 降到 49。与此同时，六次覆盖事实数之和从 569 降至 371。fact 的付费上限 96，固定 IID 两个种子均用满，变长 IID 分别只用 22、7，变长不放回为 21、7。sum-divisors 均用满 96，固定 IID 覆盖 111 / 105，变长 IID 覆盖 104 / 108，变长不放回覆盖 106 / 109。

三种预算下，变长 IID 与固定 IID 没有同事实集合且同终图的配对。EPS 和 EPT 应与同一行 Coverage 阅读。表中保留每次新增有效操作、实际签发、原生拒绝、重复、各长度次数、不同有贡献具名请求、终图和付费差额。多个请求可涉及同一语义效果，独立列出参考事实和原生 EPT origins 的有效操作。[逐预算 Coverage、EPT、EPS](generation.csv) · [完整终图摘要与事实集合](facts.json) · [墙钟与解码耗时](timings.csv)

## 真实快照上的关联绑定

在三个程序的历史自主运行上逐请求重放，逐一核对原生请求 ID、回执及发布代。取历史离线已核验有贡献的 63 个非零父「窗口 × Recipe」。每组固定同一决策状态、同一正确活跃 Recipe，断言所有角色的可见具名引用集合完全一致。每种寻址签发 16 次，整批由同起点原生分叉执行，按请求 origin 统计具有新增贡献的次数。批内重复保留。审计另外抽至多 32 条原生证明，核验后取至多四个有贡献见证做给定前缀诊断。该选择偏向已知可计算的窗口，无法外推为所有窗口的绑定成功率。[逐状态结果与具名见证](interventions.jsonl) · [核验实现](../../variable_binding_audit.py)

| 原生子集 | 每组签发 | 当前 KV 有贡献 / binding 拒绝 | 历史寻址有贡献 / binding 拒绝 | 全域扁平有贡献 / binding 拒绝 |
|---|---:|---:|---:|---:|
| 一父，历史条件网络 | 496 | 100 / 0 | 102 / 0 | 100 / 0 |
| 二父，联合稀疏索引 | 368 | 37 / 247 | 55 / 26 | 37 / 246 |
| 三父，联合稀疏索引 | 48 | 3 / 30 | 4 / 1 | 3 / 35 |
| 三父，历史条件网络回退 | 96 | 0 / 96 | 20 / 52 | 0 / 96 |

历史寻址在三父上的 24 次有贡献请求中，20 次来自 532、534 的条件网络回退；这部分不能记作联合索引收益。二父上，大量通过绑定的请求仍被原生判为重复或缺少新增效果。两次正确寻找具名引用并不保证两次不同的新增计算。

当前 KV 已对所有公开 owner 和完整静态类型域中的端口进行神经打分。设 owner logit 为 u、端口 logit 为 v，owner 公开兄弟端口总数为 n。现有分解在类型域内等价于 softmax(u+v−log n)。扁平对照保留同一模型、Query、Key、前缀和静态类型域，直接对具名引用计算 softmax(u+v)。在实际审计的每个扁平前缀上加回归一化校正后，都逐域核对了两者的分布。这一对照检验 owner/port 读出，并未增加新的关系特征。稀疏组使用原历史冻结权重、字段表示、静态接线、跨头 posting 和探索分量。因此历史组的差异包括关系表示与采样算法，无法单独归为学习收益。

在抽到的原生见证上，当前 KV 的首父正确 owner 平均概率为 96.2%，正确 owner 内具体具名端口平均概率仅 36.8%（150 个见证）。给定正确首父后，二父任务的正确次父平均概率为 33.7%，历史联合索引为 55.4%。三父任务给定正确前两父时，KV 在 22 个见证上的第三父 owner 平均概率为 13.3%，对应 owner 内正确端口概率为 100%。同类型替换已绑定前缀后，后续概率分布确实会改变。当前结果指向多个具体薄弱处，包括同一 owner 内挑选首端口、利用跨父接线、在三父后段找对 owner。它不能证明整体 Cell embedding 必须更换。历史稀疏索引的后续条件概率用 2,048 次给定前缀抽样估计，其余见证概率由实际分布直接读取。

## 独立寻址验收与成本

另在固定容量 IID 下让冻结模型自主选择模板和 Higher 变体，分别替换父寻址。历史路径只遍历已发布的静态类型域并在神经特征上寻址，CPU 不检查字段相等或 guard。其向量来自历史编码器。当前 Cell 接口中未公开的内部端口不能进入发射域。完整 Token 的根、首父、变体及后续角色的基本随机数按相同顺序消费；posting 二级抽样使用单独随机流。更早的选择改变原生状态后不要求轨迹继续相同。CPU PyTorch 单线程执行当前 KV 和扁平读出，历史稀疏/回退路径调用 Metal。状态更新、posting 构造、设备传输和具名结果回读均在该次运行的墙钟内。加载冻结文件与构造静态实验环境在运行前完成。

完整调度，KV / 历史 / 扁平在 fact 覆盖 61 / 77 / 68 个事实，在 loopfact 覆盖 78 / 94 / 78，在 sum-divisors 覆盖 147 / 158 / 147。历史寻址的覆盖在这一个权重和生成种子组合上均有增加，但整页成本较高。loopfact 的 78 / 78 配对具有同事实同终图，在另行正反序复测中，1,332 个付费请求和 93 个有效操作均相同。KV 墙钟为 13.08 / 13.11 秒，扁平为 8.22 / 8.28 秒，EPS 约从 7.10 升至 11.28。这个收益属于 CPU 上的寻址读出和实现成本，未改变此轨迹的计算发现能力。sum-divisors 两个 147 的终图不同。逐预算的付费、实际拒绝及墙钟可用于区分效果与代价。[自主 A/B/C](free-binding.csv) · [同终图顺逆序复测](matched-binding.csv)

设备上另测了已有线性读出的 IID 整批长度采样。真实留出状态驻留 MPS，生成一张随机矩阵，以行前缀求每个样本首次结束前的长度。逐例与同一随机数的 CPU 结果核对。在容量 16、批量 128 下，64 次连续调用、五块计时的中位数约 62 微秒/批。该数仅计驻留设备的边界计算；正式原生运行使用上述已有解码后端。页内不放回需要逐步更新剩余叶子质量，未套用 IID 前缀公式。[设备测量](device.json)

## 复现

工作目录为 benchmarks/pass3-cell-gpu/recurrent-generator/instruction_pointer。输入沿用 rule-publication 的两个 both 检查点、foundation-curves 的原生正例与 Wake 审计、multi-association 的历史原生轨迹和 selective-partner 的冻结权重。原始 JSON、逐请求 UID、两份本轮边界权重在 ARTIFACT_ROOT/conditional-value/variable-completion；摘要覆盖每个正式输出。正式神经执行只由模型生成具名请求，离线精确搜索、目标证明及原生分叉只用于监督与诊断。没有新增 CCP 操作或改动 Runtime 语义。[原始文件校验值](manifest.json)

```sh
export ARTIFACT_ROOT='/Volumes/Extreme SSD/eggfuse-experiments'
export CELL_DATA=/tmp/dfm-local/data
export CELL_COMPILER=/tmp/cost-audit-build/release/eggfuse-cell-compiler
export CELL_REPLAY=/tmp/cost-audit-build/release/examples/cell_token_replay
export PYTHON=/tmp/egg-txn-ml/bin/python
sh variable_reproduce.sh
"$PYTHON" -m unittest test_variable_completion test_rule_publication test_constructible test_competition test_multirule_discovery test_head_joint_index test_partner_index
```

固定容量、变长 IID、变长不放回和原固定不放回均完成了独立执行。归因轮和不带归因的重复轮逐一核对事实集合、图摘要、有效操作、协议计数与生成计数。长度主表使用不带逐请求归因的正反序两次墙钟，附两次范围。不同测量作业有部分重叠，外部负载可影响 EPS。matched-binding 另在这些作业结束后单独复测。样本仅有两个边界训练种子和一个生成种子，关联自主对照仅有一个权重种子。

本轮 51 项相关回归测试通过。本地 Cargo sum-bits compile、run、五次 bench 均完成；既有 sum-bits 原生合同验收返回 pass。另逐项与 5af63c3e 的原固定不放回生产对照核对，18 组事实集合、终图、协议计数与有效操作全部一致。
