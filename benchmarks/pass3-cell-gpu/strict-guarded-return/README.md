# Guarded internal instructions on an explicit returned fact

A compiled edge maps a producer constructor operation to a consumer's only table atom, its pivot. This extension binds repeated fields and literals by source semantics and allows ordered scalar comparisons or integer arithmetic whose inputs have all been provided by that pivot or earlier primitives. Every closed invocation still reads an actual prior FactRef (including its generation) and releases at its original Run. A false condition leaves that identity on the ordinary path. The partial issuer skips only independently established addresses before scoring the residual.

In 3mm, allowing all eligible plain edges removed 9,199 separate proposals; guarded edges removed 12,095, and two connected edges 15,217. Forward explicit-parent FEPT was 0.16603 (leaf), 0.16881, 0.16971 and 0.17069 respectively. The counts of final-visible identities actually created by typed instructions inside internally released children were 0, 3,439, 4,340 and 4,805. Nodes from runtime dynamic elaboration and from separately selected child tokens are recorded separately. On sum-bits the same arms removed 0, 384, 516 and 580 packets; final-visible typed additions inside the signed template were 0, 68, 77 and 84. No total graph increase is claimed.

Source binding and hidden-state decision digests are checked against leaf; child attribution is derived from actual owner and signed-commit paths. Only typed constructor ports born in the selected producer Cell qualify. Existing interned facts retain the ordinary path. Median inference times and individual samples are archived. This is a compiled action-space ablation, without retraining an instance policy.
