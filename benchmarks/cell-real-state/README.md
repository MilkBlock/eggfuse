# 实数 Cell 状态：从 ridge 读出到自主状态转移

本实验使用**稠密、带正负小数的实数状态和权重**，研究能否用浮点计算
直接推进后继状态。它不把关系矩阵的 0/1 当作运行时状态，不在每步
解码后调用符号解释器，也不调用 nearest-state 查表来修正预测。

结论：小型实数向量可以保留本测试的状态信息，但所测试的转移模型
尚不能可靠地连续运行。`semantic_takeover_accepted: false`。
这是独立有限模型研究；不是实际 Cell CPU/native egglog 接管，没有
GPU 执行、速度收益或全量 egraph 可压缩性的结论。

## 复现

```sh
python3 -m venv out/cell-real-state/venv
out/cell-real-state/venv/bin/python -m pip install -r benchmarks/cell-real-state/requirements.txt
OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=4 out/cell-real-state/venv/bin/python benchmarks/cell-real-state/study.py --output out/cell-real-state/new
```

使用新输出目录。当前检查使用 NumPy 2.5.4，执行约 11 秒，包括独立
teacher 校验、全部模型训练和诊断；这个时间不是推理性能结果。
模型数组 `selected.npz` 留在忽略的 `out/`，只提交源和文本结果。
未修改 Cargo/compiler/runtime，因此未重复跑 CPU 分支的性能测试。

## 与之前 ridge 的关系

历史 `experiments/resident_ridge/compiler.py` 将 state/ready/alias 特征
编码到 256 个实数坐标，调用带中心化的多输出 ridge，预测转换标签。
GPU 仍执行精确 guard 和槽映射；后继坐标由已知符号特征增量更新。
它没有验证“由预测值产生的后继向量继续驱动下一次转移”。

本轮保留中心化、多输出 ridge、正则项和半精度系数的基本计算方式，
将监督目标改为**后继实数状态的增量**。由于特征和标签改变，这不是
对旧模型的重跑，也不继承其 native 证书或准确率。
旧实现的 scale-256 是存储约定，这里没有使用它。训练用 FP64 求解，
执行的输入和矩阵系数经过 FP16 量化，点积用 FP32，偏置用 FP32。
新模型参数和旧数据文件相互独立，不依赖旧 worktree 才能复现。

当前实际执行记录并没有证明所有 Cell 都能共享小型连续状态，本轮也
没有从真实 catalog 自动抽取训练数据。它首先检验更小的必要条件：
一个带结构共享、非线性条件和 union 反馈的有限片段能否做到这件事。

## Teacher 和严格的结构划分

固定图包含 6 个边界端口及 12 个已有构造子，使用 F/G/H/Pair 四种
运算符。H 的输入来自前面的 F/G 结果，存在共享和多输入汇合。
两组可启用的正规则包括：重复参数条件导致 F/G 结果合并；H 的结果
相等和额外边界等式共同成立时，再合并边界端口。每步重新求有限
congruence/规则闭包。完整节点和规则在 `NODES` 和 `close()` 中。

事件包括 15 种边界端口 union、2 种规则启用。所有节点预先存在，
没有一般项生成、删除、标量运算、全局构造子分配或源 Run 效果顺序。
“规则启用”只是有限正模型的状态分量，不代表 egglog Run 调度。

枚举边界 partition 和启用位，再按完整闭包去重，得到 806 个不同
语义状态。每个状态包含 153 个节点对的 Eq 观测及 2 个启用位；其中
**只有 38 个观测会变化**，不能把去除常量带来的缩小算成学习收益。

以完整状态哈希划分 496 个训练、154 个验证、156 个测试状态。
训练边要求**源状态和目标状态都属于训练集**，共有 6,224 条边。
编码器和读出也只使用训练状态。不是仅替换节点编号作留出。

独立的 bitset 传递闭包实现不使用 union-find/hashcons，与 teacher
逐条核对了全部 13,702 个状态转移；另检查 17 个动作的幂等性和 289
组动作的可交换性，全部通过。它验证这个数学模型，不扩展仓库的
native/sum-bits 语义验收合同。

## 浮点表示究竟是什么

初始编码用训练集拟合 PCA 基，中心化后按训练标准差缩放：

```
h = ((facts - mean) @ learned_basis) / scale
```

`facts` 只用于离线训练和实例初始化。自主执行只持有 h 和事件编码。
例如某个 32 维状态的前几个坐标为：

```
[0.43164, 0.06384, -1.80762, 0.59912, 0.54639, -1.13379, ...]
```

最终模型读出权重的一段为：

```
[0.07001, -0.09698, -0.22839, 0.20874, -0.13330, 0.17273, ...]
```

坐标混合承载多个观测。156 个留出状态使用 32 维编码后，通过 ridge
读出和最终阈值，全部观测均正确；16 维只有 75.64% 的状态全对。
这是有限测试上的读出结果，不是严格无损编码证明。32 个 FP16 占 64
字节，也明显大于 38 个布尔位打包后的空间；不声称物理存储更小。
64 维还超过了变化观测数，它是扩宽对照。

目标是：

```
h_next = h + phi(h, event) @ W + bias
```

比较了六种 phi：

1. 当前实数状态与 16 维实数事件编码拼接。
2. 加入状态与事件的乘性交互。
3. 256 个随机实数投影，经过 tanh。
4. 768 个随机实数投影，经过 tanh。
5. 每个事件一个线性 ridge 算子，直接利用已知动作类型。
6. 每个事件一个带全部二次状态特征的 ridge 算子。

最后还训练了一个 128 隐单元的 tanh 模型：从 ridge 初始化开始，
用 Adam 同时更新投影和读出，反向传播通过连续三个预测步骤，损失
包含状态误差及观测误差。编码器仍固定为 PCA，**没有联合训练编码器**。
4,096 条三步训练序列的所有状态都在训练集。训练 1,600 步，每 200
步按验证集表现选择 checkpoint；测试集不参与 checkpoint 选择。

## 单步正确不等于可接续

单步测试覆盖 156×17=2,652 条边。每次输入真实初态编码，要求输出
的所有观测同时正确。自主测试从留出状态开始，运行 624 条、各 12
步的事件序列，**只在第一步提供真实编码**。中间不读出、不阈值修复、
不重新编码真值。每步的 teacher 状态仅用于事后检查。

32 维结果如下：

| 模型 | 单步完整状态正确 | 其中真实变化正确 | 12 步全程正确 |
|---|---:|---:|---:|
| 共享线性 ridge | 29.19% | 7.45% | 0/624 |
| 乘性交互 ridge | 42.50% | 25.34% | 1/624 |
| 随机 tanh 256 + ridge | 21.83% | 5.69% | 0/624 |
| 随机 tanh 768 + ridge | 20.10% | 11.79% | 0/624 |
| 每动作线性 ridge | 60.60% | 48.97% | 24/624 |
| 每动作二次 ridge | 73.11% | 67.06% | 0/624 |
| 可训练 tanh，三步损失 | 24.25% | 4.40% | 0/624 |

空操作通常比真实变化容易，JSON 单列二者，避免空操作掩盖错误。
全程要求比只看最终一步严格：例如每动作线性模型的第 12 步已有
95.35% 状态全对，但完整轨迹只有 3.85% 全对。许多序列最后趋向
合并充分的状态，不能据此声称此前的过程正确。

有的多项式模型会数值漂移；一个 64 维随机非线性配置出现 FP16
非有限值。检查记录首次失效步，不将 NaN 比较结果当作正确预测。
所有配置都未达到语义接管条件。这不排除其他可训练网络、优化器、
损失或表示，只表明这一批明确列出的模型没有解决问题。

## 一个更直接的结构诊断：闭合需要多大空间

在完整的 806 状态域上，令 Q 的列为当前可观察函数和常数。每个动作
a 都有精确状态映射 T_a。反复加入 `Q(T_a(s))` 并取列空间，直到所有
动作都能在同一线性空间中表示。这是离线数值秩诊断，使用全部状态，
**不能当成留出学习结果**。

维数依次为：

```
36 → 380 → 579 → 641 → 645 → 645
```

三个 SVD 截断阈值 1e-7、1e-8、1e-9 得到同一结果，最大不变性残差
约 8.47e-12。对于这个有限模型，“所有动作都用精确线性状态算子且
观测也线性读出”需要很大的空间；这是数值证据，不是精确代数证书。
它不构成任意非线性网络所需维数的下界，更不证明真实 egraph 稠密。

这解释了为什么不能只让 ridge 增大宽度：保持快照可读出的表示，
在后继变换下未必闭合。没有闭合性，后继预测可以离开合法状态所在
区域；下一次矩阵运算继续放大错误。

## 下一项值得验证的方向

应让编码本身同时服务于读出和多步转移；本轮只训练快照 PCA，或在
固定编码上拟合转换。更具体的约束已经由 teacher 检查得到：重复
union 的幂等性、该有限正闭包中动作的可交换性，以及结论单调增加。
这些可作为训练约束和反例来源，不能自动推广到有序可变效果。

另一个方向是利用实际 Cell 定义把稳定结构放进共享权重，只编码
会变化的边界和绑定；由 Bake 给出必要的角色交互，再学习低维乘性
特征。当前二次展开有 305,456 个参数，却没有稳定滚动能力，不能
把它直接包装成一个有效的 GPU 后端。最终还要计入初始编码、模型
分派、精确边界校验和残余路径。

本轮停在 CPU 数值验证，没有对错误模型启动 GPU 速度对比。
